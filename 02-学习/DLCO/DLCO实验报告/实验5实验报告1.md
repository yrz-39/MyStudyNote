## 实验目的

1. 掌握利用 ROM 组件实现指令存储器的设计方法。
2. 掌握 ASCII 点阵字库的使用方法。
3. 掌握利用 RAM 组件实现按字节存取的数据存储器的设计方法。
4. 掌握实现 RV32I 存取指令的设计方法。
5. 掌握 RV32I 下地址逻辑部件的设计方法。
6. 掌握 RV32I 指令译码、反汇编的实现方法。
7. 掌握 RV32I 立即数扩展器的设计方式。
8. 根据 RV32I 指令执行过程，掌握 RV32I 运算类指令数据通路的设计方法。
9. 掌握跳转控制器的设计方法。

## 实验内容

### 1. 只读存储器 ROM 实验

#### 电路功能

本电路利用 ROM 保存 ASCII 码 8×16 点阵字库。输入一个 ASCII 码后，电路先判断该码是否在可显示字符范围 `0x20~0x7F` 内；若合法，则计算该字符在字库 ROM 中的起始地址，并同时读出 16 行点阵数据，送到 8×16 LED 点阵显示；若输入不合法，则输出错误标志 `CodeErr=1`。

#### 整体方案设计

该实验不需要复杂的顶层 CPU 设计，只需要完成 ASCII 码到点阵显示的组合逻辑和 ROM 读取逻辑。核心思路是：

`字符起始地址 = (ASCII_CODE - 0x20) << 4`

因为每个字符占 16 字节，所以减去 `0x20` 后左移 4 位，即乘以 16，得到该字符点阵数据在字库中的起始地址。

#### 输入输出引脚

| 引脚名称 | 方向 | 位宽 | 作用 |
|---|---:|---:|---|
| `ASCII_CODE` | 输入 | 8 bit | 输入待显示字符的 ASCII 编码 |
| `row0 ~ row15` | 输出 | 8 bit | 16 行点阵数据，每行 8 bit，对应 LED 点阵的一行 |
| `CodeErr` | 输出 | 1 bit | ASCII 码错误标志。输入不在 `0x20~0x7F` 时为 1 |

#### 子模块简单介绍

| 子模块 | 功能 |
|---|---|
| ASCII 合法性判断模块 | 判断输入是否在可显示字符范围内。合法时 `CodeErr=0`，非法时 `CodeErr=1` |
| 地址生成模块 | 对输入 ASCII 码执行 `(ASCII_CODE - 0x20) << 4`，得到点阵字库起始地址 |
| 16 个 ROM 字库模块 | 每个 ROM 保存同一份 `ascii8-16.zk` 字库文件，分别读取第 0 行到第 15 行点阵数据 |
| LED 点阵显示模块 | 接收 16 行 8 bit 数据，在 LED 点阵中显示字符形状 |

### 2. 数据存储器 RAM 实验

#### 电路功能

本电路实现一个 256KB 的 RV32I 数据存储器。RV32I 的访存指令不仅有按字访问的 `lw/sw`，还有按半字访问的 `lh/lhu/sh` 和按字节访问的 `lb/lbu/sb`。因此，数据存储器需要根据 `MemOp` 和地址低两位 `Addr[1:0]` 判断当前访问的数据宽度，选择对应的字节 RAM，并在读取时完成零扩展或符号扩展。

为了方便按字节访问，本实验使用 4 片 8 bit RAM 组成一个 32 bit 数据存储器：

- `RAM0`：保存最低字节 `[7:0]`
- `RAM1`：保存次低字节 `[15:8]`
- `RAM2`：保存次高字节 `[23:16]`
- `RAM3`：保存最高字节 `[31:24]`

#### 输入输出引脚

| 引脚名称 | 方向 | 位宽 | 作用 |
|---|---:|---:|---|
| `Addr` | 输入 | 18 bit | 数据存储器字节地址 |
| `Din` | 输入 | 32 bit | 写入数据 |
| `WE` | 输入 | 1 bit | 写使能，1 表示写存储器 |
| `CLK` | 输入 | 1 bit | 时钟信号 |
| `Clr` | 输入 | 1 bit | 清零信号 |
| `MemOp` | 输入 | 3 bit | 访存类型控制信号 |
| `Dout` | 输出 | 32 bit | 读取并扩展后的数据 |
| `AlignErr` | 输出 | 1 bit | 地址未对齐或 MemOp 未定义时输出 1 |

#### 子模块简单介绍

| 子模块 | 功能 |
|---|---|
| 片选控制模块 | 根据 `MemOp` 和 `Addr[1:0]` 生成 `SEL3~SEL0` |
| 4 片 8 bit RAM | 分别保存 32 bit 数据的 4 个字节 |
| 写数据选择模块 | 写字节或半字时，将 `Din` 的低 8 bit 或低 16 bit 写入对应 RAM |
| 读数据拼接模块 | 根据片选结果从不同 RAM 取出字节并拼接 |
| 位扩展模块 | 对 `lb/lh` 做符号扩展，对 `lbu/lhu` 做零扩展 |
| 对齐检测模块 | 检查半字、字访问地址是否自然对齐 |

### 3. 取指令部件 IFU 实验

#### 电路功能

IFU 是取指令部件，主要功能是保存当前程序计数器 `PC`，根据控制信号计算下一条指令地址，并从指令存储器中读出当前指令 `IR`。复位信号 `Reset=1` 时，下一次时钟有效边沿会把 `Initial Address` 写入 PC；否则，PC 根据顺序执行、跳转或分支情况更新。

#### 输入输出引脚

| 引脚名称 | 方向 | 位宽 | 作用 |
|---|---:|---:|---|
| `Initial Address` | 输入 | 32 bit | 复位时加载到 PC 的初始地址 |
| `Imm` | 输入 | 32 bit | 分支或跳转立即数 |
| `BusA` | 输入 | 32 bit | `jalr` 指令中来自 `rs1` 的目标基地址 |
| `CLK` | 输入 | 1 bit | 时钟信号 |
| `Reset` | 输入 | 1 bit | 复位信号，高电平有效 |
| `NPCASrc` | 输入 | 1 bit | 下一地址加法器 A 输入选择，0 选 PC，1 选 BusA |
| `NPCBSrc` | 输入 | 1 bit | 下一地址加法器 B 输入选择，0 选常数 4，1 选 Imm |
| `PC` | 输出 | 32 bit | 当前指令地址 |
| `IR` | 输出 | 32 bit | 当前指令机器码 |

#### 子模块简单介绍

| 子模块 | 功能 |
|---|---|
| PC 寄存器 | 保存当前指令地址 |
| 下地址加法器 | 计算 `PC+4`、`PC+Imm` 或 `BusA+Imm` |
| 多路选择器 | 根据 `NPCASrc` 和 `NPCBSrc` 选择加法器输入 |
| 指令 ROM | 根据 `PC[17:2]` 读出 32 bit 指令 |

### 4. 取操作数部件 IDU 实验

#### 电路功能

IDU 是取操作数部件，功能包括指令字段解析、寄存器堆读写、立即数扩展以及 ALU 输入选择。输入 32 bit 指令 `IR` 后，IDU 从指令中分离出 `opcode`、`rd`、`funct3`、`rs1`、`rs2`、`funct7` 等字段，并根据 `ExtOp` 生成对应类型的 32 bit 立即数 `Imm`。同时，IDU 根据 `rs1` 和 `rs2` 读取寄存器堆，得到 `BusA` 和 `BusB`，再根据 `ALUASrc` 和 `ALUBSrc` 生成 ALU 的两个输入 `DataA` 和 `DataB`。

#### 输入输出引脚

| 引脚名称 | 方向 | 位宽 | 作用 |
|---|---:|---:|---|
| `IR` | 输入 | 32 bit | 当前指令机器码 |
| `PC` | 输入 | 32 bit | 当前指令地址 |
| `BusW` | 输入 | 32 bit | 写回寄存器堆的数据 |
| `ExtOp` | 输入 | 3 bit | 立即数扩展类型 |
| `RegWr` | 输入 | 1 bit | 寄存器堆写使能 |
| `Clk` | 输入 | 1 bit | 时钟信号 |
| `ALUASrc` | 输入 | 1 bit | ALU A 输入选择，0 选 BusA，1 选 PC |
| `ALUBSrc` | 输入 | 2 bit | ALU B 输入选择，0 选 BusB，1 选 4，2 选 Imm |
| `OP` | 输出 | 7 bit | 指令操作码 opcode |
| `Funct3` | 输出 | 3 bit | 指令 funct3 字段 |
| `Funct7` | 输出 | 7 bit | 指令 funct7 字段 |
| `Imm` | 输出 | 32 bit | 扩展后的立即数 |
| `BusA` | 输出 | 32 bit | rs1 寄存器读出值 |
| `BusB` | 输出 | 32 bit | rs2 寄存器读出值 |
| `DataA` | 输出 | 32 bit | ALU A 端输入 |
| `DataB` | 输出 | 32 bit | ALU B 端输入 |

#### 子模块简单介绍

| 子模块 | 功能 |
|---|---|
| 指令译码模块 | 用分线器从 IR 中取出 opcode、rd、funct3、rs1、rs2、funct7 |
| 立即数扩展器 | 根据 ExtOp 输出 I/U/S/B/J 类型立即数 |
| RegFile 寄存器堆 | 根据 rs1、rs2 读寄存器，根据 rd 和 RegWr 写寄存器 |
| ALU 输入选择模块 | 由 ALUASrc、ALUBSrc 决定 DataA、DataB 的来源 |

### 5. 数据通路实验

#### 电路功能

数据通路用于把前面实验完成的 IFU、IDU、ALU、DataRAM 和跳转控制器连接起来，实现 RV32I 指令从取指、译码、执行、访存到写回的完整数据流。对于不同类型的指令，数据通路通过控制信号选择不同的数据来源和去向：

- 运算指令：寄存器读出数据进入 ALU，结果写回寄存器；
- 访存指令：ALU 计算有效地址，再访问 DataRAM；
- 跳转/分支指令：跳转控制器根据比较结果产生 `NPCASrc` 和 `NPCBSrc`，控制 PC 更新；
- `jal/jalr/auipc`：使用 PC 参与计算，并把 `PC+4` 或 `PC+imm` 写回寄存器。

#### 输入输出引脚

| 引脚名称 | 方向 | 位宽 | 作用 |
|---|---:|---:|---|
| `Initial Address` | 输入 | 32 bit | 程序起始地址 |
| `clk` | 输入 | 1 bit | 时钟信号 |
| `ReSet` | 输入 | 1 bit | 复位信号 |
| `ExtOp` | 输入 | 3 bit | 立即数扩展控制 |
| `RegWr` | 输入 | 1 bit | 寄存器堆写使能 |
| `MemWr` | 输入 | 1 bit | 数据存储器写使能 |
| `MemtoReg` | 输入 | 1 bit | 写回数据选择，0 选 ALU，1 选 DataRAM |
| `MemOp` | 输入 | 3 bit | 访存宽度与扩展方式 |
| `ALUASrc` | 输入 | 1 bit | ALU A 输入选择 |
| `ALUBSrc` | 输入 | 2 bit | ALU B 输入选择 |
| `ALUctr` | 输入 | 4 bit | ALU 运算控制 |
| `BandJ` | 输入 | 3 bit | 分支/跳转控制编码 |
| `PC` | 输出 | 32 bit | 当前指令地址 |
| `BusW` | 输出 | 32 bit | 写回寄存器的数据 |
| `Din` | 输出 | 32 bit | 写入 DataRAM 的数据 |
| `NPCASrc` | 输出 | 1 bit | IFU 下一地址 A 输入选择 |
| `NPCBSrc` | 输出 | 1 bit | IFU 下一地址 B 输入选择 |

#### 子模块简单介绍

| 子模块 | 功能 |
|---|---|
| IFU | 保存 PC，并根据 `NPCASrc/NPCBSrc` 产生下一条指令地址 |
| 指令 ROM | 根据 PC 输出当前指令 IR |
| IDU | 对 IR 译码，读寄存器，生成立即数和 ALU 输入 |
| ALU | 根据 `ALUctr` 进行加、减、逻辑、移位、比较等运算 |
| DataRAM | 实现字节、半字、字粒度的数据存取 |
| BandJ 跳转控制器 | 根据 `BandJ`、`Zero`、`Result[0]` 生成 `NPCASrc/NPCBSrc` |
| 写回选择器 | 根据 `MemtoReg` 选择 ALU 结果或 DataRAM 输出写回寄存器 |

## 思考题解析

### 1. 如何利用 ROM 实验实现滚动显示功能，在 3 个 LED 点阵矩阵中左右滚动显示 5 个 ASCII 字符，如 “NJUCS”？

可以把 5 个字符的 8×16 点阵数据从 ROM 中依次读出，然后在水平方向上拼接成一个宽度为 `5×8=40` 列、高度为 16 行的大点阵。3 个 LED 点阵一共能显示 `3×8=24` 列，因此只需要增加一个滚动计数器 `offset`，每隔一定时钟周期让 `offset` 加 1，然后从 40 列大点阵中取出从 `offset` 开始的连续 24 列送给 3 个 LED 点阵。这样，随着 `offset` 不断变化，显示窗口就会在 5 个字符组成的大点阵上移动，从而实现左右滚动显示。

### 2. 如果 PC 寄存器、寄存器堆和数据存储器写入数据的时钟触发边沿不一致，会对程序执行结果有什么影响？

如果这些模块的触发边沿不一致，就可能出现数据前后不一致的问题。例如 PC 已经在上升沿更新到了下一条指令，但寄存器堆或数据存储器还没有在同一时刻完成写入，那么下一条指令读取到的可能是旧数据；反过来，如果数据存储器过早写入，也可能导致访存结果与当前指令不对应。这样会破坏单周期 CPU 中“一个周期完成一条指令”的假设，导致取指、译码、执行、访存、写回之间出现时序错乱，程序执行结果可能错误。

### 3. CPU 启动执行后，如何实现在当前程序结束后 CPU 不再继续往下执行？

可以在程序末尾加入一条自循环指令，使 PC 一直停留在程序结束位置。例如使用：

```asm
jal x0, 0
```

该指令不会写回有效寄存器，并且会跳转到自身地址，因此 CPU 会一直执行这一条指令，不再继续向后取指。
