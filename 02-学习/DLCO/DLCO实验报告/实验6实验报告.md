### 1.控制器设计实验

#### 整体方案设计
控制器输入当前指令的操作码和功能码，通过译码逻辑产生控制信号。设计时先根据不同指令的 `opcode` 区分指令大类，再根据 `funct3` 和 `funct7[5]` 区分具体运算类型，最后输出对应控制信号。
##### 子模块说明

| 子模块      | 功能                                                                      |
| -------- | ----------------------------------------------------------------------- |
| 操作码译码模块  | 根据 `opcode[6:0]` 判断指令大类，如 R 型、I 型、Load、Store、Branch、JAL、JALR、LUI、AUIPC。 |
| 功能码译码模块  | 根据 `funct3` 和 `funct7[5]` 区分具体运算，如加减、移位、比较、逻辑运算等。                       |
| 控制信号生成模块 | 根据指令类型输出 `ExtOp`、`ALUctr`、`MemOp`、`BandJ` 等控制信号。                        |
| 写使能控制模块  | 产生 `RegWr`、`MemWr`、`MemtoReg` 等信号，控制寄存器堆和数据存储器读                         |


##### 输入输出引脚
| 引脚名        |  位宽 | 类型  | 说明                                                |
| ---------- | --: | --- | ------------------------------------------------- |
| `opcode`   |   7 | 输入  | 指令操作码字段 `Instr[6:0]`。                             |
| `funct3`   |   3 | 输入  | 指令功能码字段 `Instr[14:12]`。                           |
| `funct7`   |   7 | 输入  | 指令功能码字段 `Instr[31:25]`，主要使用 `funct7[5]`。          |
| `ExtOp`    |   3 | 输出  | 立即数扩展类型选择信号。                                      |
| `RegWr`    |   1 | 输出  | 寄存器堆写使能信号，高电平有效。                                  |
| `ALUASrc`  |   1 | 输出  | ALU 输入端 A 选择信号，0 选择 `R[rs1]`，1 选择 `PC`。           |
| `ALUBSrc`  |   2 | 输出  | ALU 输入端 B 选择信号，00 选择 `R[rs2]`，01 选择常数 4，10 选择立即数。 |
| `ALUctr`   |   4 | 输出  | ALU 运算控制信号。                                       |
| `BandJ`    |   3 | 输出  | 分支跳转控制信号，送入跳转控制器。                                 |
| `MemtoReg` |   1 | 输出  | 寄存器写回数据选择信号，0 为 ALU 结果，1 为数据存储器输出。                |
| `MemWr`    |   1 | 输出  | 数据存储器写使能信号，高电平有效。                                 |
| `MemOp`    |   3 | 输出  | 数据存储器访存类型控制信号。                                    |

### 2.单周期CPU设计实验

#### 整体方案设计
单周期 CPU 是指每条指令都在一个时钟周期内完成取指、译码、执行、访存和写回操作。本实验在实验 5 数据通路的基础上加入控制器，组成完整的 RV32I 单周期 CPU，使其能够执行整数运算、存储器访问、条件分支和无条件跳转指令。

CPU 运行时，指令存储器根据 PC 输出当前指令，控制器根据指令字段产生控制信号，IDU 读取寄存器和立即数，ALU 执行运算或地址计算，DataRAM 完成访存，最后通过写回选择器将结果写回寄存器堆。程序执行到 `ecall` 指令时，控制器产生 `Halt=1`，使 PC 停止更新，CPU 停止执行。
##### 子模块说明

| 子模块 | 功能 |
|---|---|
| IFU 取指令部件 | 保存和更新 PC；根据 `NPCASrc`、`NPCBSrc` 计算下一条指令地址；当 `Halt=1` 时停止 PC 更新。 |
| 指令存储器 ROM | 存放 RV32I 机器代码，根据 `PC[17:2]` 输出 32 位指令。 |
| 控制器 | 根据 `opcode`、`funct3`、`funct7` 产生数据通路控制信号，并在 `opcode=0x73` 时输出 `Halt=1`。 |
| IDU 取操作数部件 | 完成指令译码、立即数扩展、寄存器堆读取和 ALU 输入选择。 |
| ALU | 执行加减、逻辑、移位、比较等运算，并输出 `Zero`、`Result0` 等状态信号。 |
| DataRAM 数据存储器 | 完成 `lb/lh/lw/lbu/lhu` 和 `sb/sh/sw` 等访存操作。 |
| BandJ 跳转控制器 | 根据 `BandJ`、`Zero`、`Result0` 输出 `NPCASrc`、`NPCBSrc`。 |
| 写回选择模块 | 根据 `MemtoReg` 选择 ALU 结果或 DataRAM 输出作为 `BusW` 写回寄存器堆。 |
| 周期计数器 | 统计 CPU 程序执行周期数，复位时清零，`Halt=1` 时停止计数。 |

##### 输入输出引脚

| 引脚名 | 位宽 | 类型 | 说明 |
|---|---:|---|---|
| `InitAddr` | 32 | 输入 | 程序初始地址，复位时写入 PC。 |
| `ReSet` | 1 | 输入 | 复位信号，高电平有效。 |
| `clk` | 1 | 输入 | CPU 时钟信号。 |
| `PC` | 32 | 输出 | 当前指令地址。 |
| `IR` | 32 | 输出 | 当前指令机器码。 |
| `BusW` | 32 | 输出 | 写回寄存器堆的数据。 |
| `Din` | 32 | 输出 | 写入数据存储器的数据。 |
| `Cycles` | 32 | 输出 | 程序执行周期计数。 |
| `Halt` | 1 | 输出 | 停止执行信号，检测到 `ecall` 时为 1。 |

### 4.冒泡排序程序测试实验

#### 4.1编写汇编源程序
```text
main:
 lw t0,0(x0) # R[t0]<-Mem[0],t0 保存排序数量 n,待排序的数字个数 n 存在 0x00 处
 addi a1,x0,1 # a1，保存常量 1
 add a2,t0,x0 # a2，保存 i，初始值为 i=n
L1:
 addi a3,x0,1 # a3，保存 j，初始值为 j=1
L2:
 slli a4,a3,2 # a4 保存 a[j]地址
 lw a6,0(a4) # 读取第 j 个元素
 lw a7,4(a4) # 读取第 j+1 个元素
 bge a7,a6,L4 # a[j]>=a[j+1] 跳转,按照带符号数比较
 sw a7,0(a4) # 交换存储
 sw a6,4(a4) # 交换存储
L4:
 addi a3,a3,1 # j=j+1
 bltu a3,a2,L2 # if j<i then 循环，序号按照无符号数比较
L3:
 sub a2,a2,a1 # i--
 bne a2,a1,L1 # if i>1 then 循环 else 则结束
 ecall # 结束执行
```

### 思考题
1. 如何在单 CPU 上实现多任务处理，例如同时执行计算累加和与数据排序两个程序，阐述思路。 
**通过保存和恢复不同程序的运行现场，让CPU在多个任务之间快速轮流执行，从宏观上实现“同时运行”效果，需要一个调度程序，在一个程序执行一定周期数后暂停其执行，保存当前状态，然后切换到另一个程序执行**
2. 在 CPU 的基础上，如何实现键盘输入、TTY 输出部件等输入输出设备的数据访问，构建完整的计 算机系统。 
**把外部设备也看成一种特殊的存储单元，用地址规定不同地址使用什么存储单元，如0x10000000用于读取键盘，0x10000004用于读取TTY等**，**这样指令不用变，只是获得操作数的地方变了**
3. 阐述如何在单周期 CPU 基础上实现多周期 CPU 
	- **把指令执行过程分成IF,ID,EX,M,WB五个阶段，增加一些中间寄存器保存每个阶段的结果，供下个周期使用**
	- **把控制器逻辑改为有限状态机控制器，使得同一个指令在不同执行阶段有不同的控制信号**
4. 阐述如何在单周期 CPU 基础上实现流水线 CPU？ 
	- **增加流水线寄存器，如IF/ID,ID/EX,EX/M,M/WB**
	- **把控制信号沿着流水线传递**
	- **增加冒险检测，处理结构冒险，控制冒险等冒险，把不同指令都按照五个阶段对齐**
