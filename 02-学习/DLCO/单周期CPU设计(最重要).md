## 1. 单周期 CPU 的核心思想
一句话概括:
	单周期CPU指每条指令都在一个时钟周期内完成，包括IF,ID,EX,M,WB五个阶段，因此CPI=1，但是时钟周期长度一般较长，要能容纳最慢指令完成(通常是lw)

| 特点   | 说明           |
| ---- | ------------ |
| CPI  | 1            |
| 时钟周期 | 由最慢指令决定      |
| 优点   | 结构直观，容易理解    |
| 缺点   | 时钟周期长，硬件利用率低 |
- ==注意：单周期CPU性能瓶颈不是CPI高，而是时钟周期太长==
