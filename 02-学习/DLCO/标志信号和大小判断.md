# 标志信号和大小判断
## 1.背景问题
- 在ALU设计中，我们的先行进位加法器会产生四个标志位:
  ==ZF,CF,SF,OF==
  这四个标志位最大的作用就是辅助判断两个数字A和B的大小关系，但是记忆这个条件十分困难，接下来给出相应的分析

## 2.原理分析
- 判断两个数的大小，我们用A-B产生的四个标志位来判断(A-B在ALU中会转换为加法计算)，具体结果不重要，只要标志位即可

| 标志位 | 含义        |
| --- | --------- |
| ZF  | 结果是否为0    |
| CF  | 是否发生进位/借位 |
| SF  | 符号位(最高位)  |
| OF  | 是否发生溢出    |
在分析之前，先明确一件事情:
	==有符号数和无符号数比较规则不同，需要用到的标志位也不同，二者共同的就是ZF==
### 2.1无符号数比较
- **无符号数只需要看ZF和CF**
  这个非常好理解，所谓无符号数就是正数，就用两个正数的加减法来看即可，当CF=1时，减法发生借位，意味着不够减，那就是A < B，反之亦然(机器中会用取反＋1去计算，所以结果会是对$2^n$取模的结果)
### 2.2有符号数比较
- 这个稍微复杂，因为可能会有溢出
正常情况下，当A-B结果中SF=0时，意味着结果是个正数，应该是A > B,但是有符号数会出现溢出,如：
```text
4位有符号数,其补码范围是-8~+7
A=1011=-5
B=0100=4

计算A-B=A+(B)补=1011+1100=10111 

结果应该是个负数(最高位是1)，但是只有4位,所以最后结果会显示成0111,发生溢出OF=1,所以不能只看SF来判断
```
==如何理解溢出OF？==
- OF可以理解成,当前结果是否可靠
  如:SF=1,OF=0说明没有溢出,当前结果可靠,所以可以直接根据SF得到结果是个负数,A < B
  SF=1,OF=1说明发生溢出,当前结果不可靠,所以要反过来,A>B
  SF=0,OF=0结果可靠,A>B
  SF=0,OF=1结果不可靠,A < B
  **注:大于的时候要考虑一下ZF,因为A=B的时候,SF=0,OF=0**
- 综上可以总结为:

| 判断                      | 结果  |
| ----------------------- | --- |
| $SF\oplus OF$ =1        | A<B |
| $SF\oplus OF$ =0且$ZF=0$ | A>B |
