## Problem Set 13：图论导引

### 套路 13.1：标准图参数快算

**题型信号**

- 出现 $K_n$、$C_n$、$W_n$、$K_{m,n}$、$Q_n$。
- 要求顶点数、边数、度数、补图、Euler/Hamilton 初判。

**第一反应**

先把标准图参数写在草稿纸上，不要直接凭图感：

| 图 | 顶点数 | 边数 | 度数特征 |
|---|---:|---:|---|
| $K_n$ | n | $n(n-1)/2$ | 每点 $n-1$ |
| $C_n$ | n | n | 每点 2 |
| $W_n$ | 按课程定义确认 | 外圈 + 辐条 | 中心度最大，外圈点通常度 3 |
| $K_{m,n}$ | $m+n$ | $mn$ | 左侧度 n，右侧度 m |
| $Q_n$ | $2^n$ | $n2^{n-1}$ | 每点度 n |

**标准答题步骤**

1. 写清图的顶点集/结构。
2. 分类型数边：完全图按组合数，二部图按左右配对，超立方体按握手定理。
3. 写度数序列，必要时检查握手定理。
4. 若题目继续问性质，再转入对应套路。

**可改编方式**

- 把 $K_n$ 改成删几条边后的图。
- 把 $K_{m,n}$ 改成左右不均衡，要求二部图边数上界。
- 把 $Q_n$ 改成二进制字符串相邻关系。

**易错点**

- $Q_n$ 边数不是 $n2^n$，因为每条边被两个端点数了两次。
- 轮图 $W_n$ 的 n 可能表示总顶点数或外圈顶点数，要按课程口径确认。

**代表训练题与参考要点**

题：求 $Q_4$ 的顶点数、边数、每点度。

要点：顶点为 4 位二进制串，共 $2^4=16$；每点可改变 4 个坐标，度为 4；边数 $16\cdot 4/2=32$。

### 套路 13.2：握手定理、度数与平均值

**题型信号**

- 出现“度数和”“奇度点”“至少存在一个顶点”“平均度”。
- 给定边数和顶点数，要求推出某点度数上下界。

**第一反应**

写：$\sum \deg(v)=2\lvert E\rvert$，平均度为 $2\lvert E\rvert/\lvert V\rvert$，并且 $\delta(G) \le 平均度 \le \Delta(G)$。

**标准答题步骤**

1. 用握手定理把边数转成度数和。
2. 若要证明“存在顶点度数 ≥/≤ 某值”，用平均值或反证。
3. 若涉及奇偶，拆成偶度顶点和奇度顶点。
4. 最后检查简单图度数范围 $0 \le d(v) \le n-1$。

**可改编方式**

- 证明奇度顶点个数为偶数。
- 证明某图不存在，因为度数和为奇数。
- 用平均度推出至少一个顶点度数不小于/不大于某值。

**易错点**

- 环对度贡献为 2；简单图通常没有环。
- 度数和必须为偶数，度序列总和为奇数直接不可能。

**代表训练题与参考要点**

题：一个无向图有 10 个顶点、24 条边，证明至少有一个顶点度数不小于 5。

要点：平均度 $2m/n=48/10=4.8$。若所有点度数都 ≤4，则度数和 ≤40，与 48 矛盾。所以至少一个点度数 ≥5。

### 套路 13.3：补图度数、自补图必要条件

**题型信号**

- 出现补图 $\bar G$、自补图、$G\cong \bar G$。
- 要求补图边数、补图度数、可能的顶点数。

**第一反应**

补图默认针对 n 顶点简单图：

- $\deg_{\bar G}(v)=n-1-\deg_G(v)$。
- $\lvert E(G)\rvert+\lvert E(\bar G)\rvert=C(n,2)$。
- 自补图必要条件：$n(n-1)$ 能被 4 整除，即 $n\equiv 0 \text{ 或 } 1 \pmod{4}$。

**标准答题步骤**

1. 说明在同一个顶点集上取补。
2. 对每个顶点用 $n-1$ 减原度数。
3. 自补图先由同构推出边数相等。
4. 用总边数一半推出整除条件。

**可改编方式**

- 给 n 问是否可能存在自补图。
- 给图的度序列，求补图度序列。
- 要求构造 n=4 或 n=5 的自补图。

**易错点**

- 自补图必要条件不是充分证明；满足 $n\equiv 0/1 \pmod{4}$ 不代表你已经构造了图。
- 补图度数公式是 $n-1-d$，不是 $n-d$。

**代表训练题与参考要点**

题：证明 6 个顶点不存在自补简单图。

要点：若自补，则 $\lvert E(G)\rvert=C(6,2)/2=15/2$，不是整数；或 $6\equiv 2 \pmod{4}$ 不满足必要条件。

### 套路 13.4：同构映射与否证不变量

**题型信号**

- 给两张图，问是否同构。
- 要求“find an isomorphism” 或 “prove not isomorphic”。

**第一反应**

先比不变量：顶点数、边数、度序列、连通分支、三角形数、圈长度、割点/桥数量、特殊度顶点邻接关系。

**标准答题步骤**

- 证明同构：
  1. 写出双射 $f$。
  2. 列出关键边的对应，或说明任意边邻接保持。
  3. 写 $uv\in E(G) \iff f(u)f(v)\in E(H)$。
- 否证同构：
  1. 找一个同构不变量。
  2. 说明两图该不变量不同。
  3. 结论：不可能同构。

**可改编方式**

- 度序列相同但三角形数不同。
- 特殊顶点数量相同但相邻关系不同。
- 图和补图同构映射。

**易错点**

- 度序列相同不能直接推出同构。
- 映射只写一半或不是双射。
- 只验证边保持，没说明非边保持；通常对简单图若边数相同且双射把所有边映到边，可足够说明，但要写清。

**代表训练题与参考要点**

题：两个 6 顶点图度序列都是 $(3,3,2,2,1,1)$，能否直接判同构？

要点：不能。度序列只是必要不变量。还需检查度为 3 的两个顶点是否相邻、三角形数、连通性等；若要证明同构必须写映射。

## Problem Set 14：连通性

### 套路 14.1：不连通图最大边数反证

**题型信号**

- “证明 n 顶点简单图若边数超过某阈值则连通”。
- 条件形如 $m > C(n-1,2)$ 或类似边数下界。

**第一反应**

反证：不连通时边数最多来自 $K_{n-1}$ 加孤立点。

**标准答题步骤**

1. 假设 G 不连通。
2. 设最大分支大小为 a，其余顶点总数为 $n-a$。
3. 边数最多时每个分支内部完全，且为了最大化应尽量集中顶点。
4. 最大不连通边数为 $C(n-1,2)$。
5. 与题设 $m>C(n-1,2)$ 矛盾。

**可改编方式**

- 证明补图某性质。
- 边数下界改成最小度下界。
- 要求构造达到上界但不连通的例子：$K_{n-1}$ 加孤立点。

**易错点**

- 不连通最大边数不是平均分分支，而是把顶点尽量集中到一个完全分支。
- 结论是“超过上界必连通”，等于上界时不一定连通。

**代表训练题与参考要点**

题：n=7 的简单图若有 16 条边，证明连通。

要点：不连通最多 $C(6,2)=15$ 条边。16>15，矛盾，故连通。

### 套路 14.2：桥、割点与分支数变化

**题型信号**

- 问“is this edge a bridge/cut edge?”、“is this vertex a cut vertex?”。
- 图中有树枝、环、两个块通过一点连接。

**第一反应**

桥看删边，割点看删点及关联边，统一比较“连通分支数是否增加”。

**标准答题步骤**

1. 记录删除前连通分支数。
2. 删除目标边/点。
3. 记录删除后连通分支数。
4. 若增加，则是桥/割点；否则不是。
5. 若原图连通，可简写为“删除后图不连通”。

**可改编方式**

- 证明树的每条边都是桥。
- 证明环上的边都不是桥。
- 构造无桥但有割点的图：两个环共享一个顶点。

**易错点**

- 割点删除的是顶点及其所有关联边。
- 原图不连通时不能只说“删后不连通”，要说分支数增加。

**代表训练题与参考要点**

题：为什么树中每条边都是桥？

要点：树中任意两点间有唯一简单通路。边 e 的两个端点之间唯一通路就是 e；删去 e 后这两个端点不再连通，分支数增加，故 e 是桥。

### 套路 14.3：k 点连通与 k 边连通

**题型信号**

- 出现 $\kappa(G)$、$\lambda(G)$、k-connected、k-edge-connected。
- 要求“删除少于 k 个点/边后仍连通”。

**第一反应**

回定义，不要凭直觉。点连通删点，边连通删边。

**标准答题步骤**

- 证明 $\kappa(G) \ge k$：任取少于 k 个顶点删除，说明剩余图仍连通。
- 证明 $\kappa(G) \le k$：构造 k 个顶点的点割。
- 证明 $\lambda(G) \ge k$：任取少于 k 条边删除，说明仍连通。
- 证明 $\lambda(G) \le k$：构造 k 条边的边割。

**可改编方式**

- 求 $K_n$、$C_n$、$K_{m,n}$ 的连通度。
- 给图找最小点割或边割。
- 用 $\kappa\le \lambda\le \delta$ 快速给上界。

**易错点**

- 点连通度与最小度有关但不一定等于最小度。
- 对完全图 $K_n$ 的点连通度通常是 $n-1$，需按定义处理删到单点的特殊情况。

**代表训练题与参考要点**

题：$C_n (n\ge 3)$ 的点连通度和边连通度是多少？

要点：删 1 个点仍是路径，连通；删 2 个合适点可不连通，所以 $\kappa=2$。删 1 条边仍是路径，连通；删 2 条合适边不连通，所以 $\lambda=2$。

## Problem Set 15：Euler 与 Hamilton

### 套路 15.1：Euler 判定

**题型信号**

- 出现 Euler trail/circuit/path/tour。
- 问是否存在经过每条边一次的路/回路。

**第一反应**

Euler 走边：先查连通性，再数奇度顶点。

**标准答题步骤**

1. 忽略孤立点后，检查所有非零度顶点是否在同一连通分支。
2. 数奇度顶点个数。
3. 0 个奇度点：有 Euler 回路。
4. 2 个奇度点：有 Euler 通路但无 Euler 回路，起终点为这两个奇点。
5. 其他情况：无 Euler 通路。

**可改编方式**

- 标准图 Euler 快判。
- $K_n$、$K_{m,n}$ 根据度数奇偶判定。
- 要求添加最少边使图有 Euler 回路。

**易错点**

- 忘记连通性。
- 把 Euler 通路和回路条件混淆。
- 孤立点在某些课程口径下不影响非零度部分的 Euler 性，要按题目定义。

**代表训练题与参考要点**

题：$K_n$ 何时有 Euler 回路？

要点：$K_n$ 每点度 $n-1$，连通。Euler 回路要求 $n-1$ 为偶数，所以 n 为奇数。

---

### 套路 15.2：$K_{m,n}$ 的 Euler/Hamilton 快判

**题型信号**

- 完全二部图 $K_{m,n}$。
- 同时问 Euler、Hamilton。

**第一反应**

分两套逻辑：Euler 看度数奇偶；Hamilton 看二部图两侧数量是否能交替。

**标准答题步骤**

- Euler：左侧点度 n，右侧点度 m；连通；回路要求 m、n 都偶；通路要求奇度点总数为 0 或 2。
- Hamilton 回路：二部图中圈必须左右交替，因此覆盖全部顶点的回路要求 $m=n\ge 2$。
- Hamilton 通路：左右交替路径覆盖全部顶点，要求 $\lvert m-n\rvert\le 1$（且非平凡情况按定义处理）。

**可改编方式**

- 给 $K_{2,3}$、$K_{3,3}$、$K_{2,4}$ 做分类。
- 要求解释为什么 $K_{2,3}$ 无 Hamilton 回路。

**易错点**

- Hamilton 回路不是看度数奇偶。
- Euler 回路不要求左右两侧数量相等。

**代表训练题与参考要点**

题：判断 $K_{2,4}$ 是否有 Euler 回路和 Hamilton 回路。

要点：左侧 2 个点度 4，右侧 4 个点度 2，全部偶且连通，所以有 Euler 回路。Hamilton 回路要求左右顶点数相等，但 2≠4，所以无 Hamilton 回路。

### 套路 15.3：Hamilton 构造、否证与 Dirac/Ore

**题型信号**

- Hamilton cycle/path。
- 出现最小度、非相邻点度数和、割点、删点后分支数。

**第一反应**

Hamilton 没有统一简单充要判定。先判断题目要你做的是：构造、用充分条件、还是否证。

**标准答题步骤**

- 构造：直接写顶点序列 $v_1-v_2-\cdots-v_n-v_1$ 并检查边存在。
- Dirac：确认 $n\ge 3$ 且 $\delta(G)\ge n/2$。
- Ore：确认任意不相邻 $u,v$ 有 $d(u)+d(v)\ge n$。
- 否证：找割点、非 2-连通、二部图两侧不等、删 S 后分支数过多等必要条件失败。

**可改编方式**

- 给图不满足 Dirac，但仍可能 Hamilton，要求构造。
- 给图有割点，要求证明无 Hamilton 回路。
- 给补图/加边后的 Hamilton 性。

**易错点**

- Dirac/Ore 不满足不能推出没有 Hamilton。
- Hamilton 回路必须回到起点，Hamilton 通路不用。
- 否证时要说明违反了哪个必要条件。

**代表训练题与参考要点**

题：为什么有割点的连通图不可能有 Hamilton 回路？

要点：若存在 Hamilton 回路，则该回路经过所有顶点。删除任一顶点后，回路剩下的部分仍给其余顶点提供一条连通路径，因此图删任一顶点后仍连通。若原图有割点，删除它会不连通，矛盾。

### 套路 15.4：线图 $L(G)$

**题型信号**

- 出现 line graph、$L(G)$。
- 要求画线图、计算线图顶点/边、判断性质。

**第一反应**

原图的“边”变成线图的“顶点”。原图两条边共享端点，则线图对应顶点相邻。

**标准答题步骤**

1. 给原图每条边编号 $e_1,e_2,\ldots$。
2. 线图顶点为这些边编号。
3. 对每一对原图边，若共享端点，则在线图中连边。
4. 检查线图边数时可按原图每个顶点的 incident edges 形成 clique 来数。

**可改编方式**

- 求 $L(C_n)$，结果仍为 $C_n$。
- 求 $L(K_{1,n})$，结果为 $K_n$。
- 用线图讨论 Euler 与 Hamilton 的联系。

**易错点**

- 不要把原图顶点直接复制到线图。
- 两条边共享一个端点即可相邻。

**代表训练题与参考要点**

题：$K_{1,4}$ 的线图是什么？

要点：$K_{1,4}$ 有 4 条边，任意两条边都共享中心点，所以线图 4 个顶点两两相邻，即 $K_4$。

## Problem Set 16：最短路算法

### 套路 16.1：Dijkstra 表格

**题型信号**

- 单源最短路、非负权、要求 “show the steps”。

**第一反应**

画表，不要只给答案。表头至少包括：已确定集合 S、当前选点、每个点的距离/前驱。

**标准答题步骤**

1. 初始化：源点距离 0，其余 $\infty$，前驱空。
2. 每轮从未确定点中选距离估计最小的点 u。
3. 把 u 加入 S。
4. 用 u 的出边/邻边松弛其他未确定点。
5. 重复直到目标确定或所有点确定。

**可改编方式**

- 只要求到某目标点，可在目标点进入 S 后停止。
- 要求恢复路径，必须记录前驱。
- 给负权边，问算法是否适用。

**易错点**

- 未确定点距离相同，任选但要保持后续一致。
- 已确定点不能再被普通 Dijkstra 更新。
- 漏前驱会丢路径分。

**代表训练题与参考要点**

题：Dijkstra 答案为什么要写前驱？

要点：距离只给最短路长度，前驱才能恢复具体路径。考试若要求 shortest path 而非 distance，只写距离不完整。

---

### 套路 16.2：Floyd 矩阵与循环不变量

**题型信号**

- all-pairs shortest paths、Floyd、矩阵更新、$D^(k)$。

**第一反应**

写递推：$d_{ij}^{(k)}=\min(d_{ij}^{(k-1)}, d_{ik}^{(k-1)}+d_{kj}^{(k-1)})$。

**标准答题步骤**

1. 初始矩阵：对角线 0，有边填权，无边填 $\infty$。
2. 第 k 轮允许 $v_k$ 作为新的中间点。
3. 对每对 $(i,j)$ 比较不用 $v_k$ 与经过 $v_k$ 的距离。
4. 最终矩阵为所有点对最短路。

**可改编方式**

- 只要求做前 1-2 轮。
- 要求证明算法正确性。
- 要求处理有负权但无负环的情况。

**易错点**

- 无边不能填 0。
- 不变量中的“中间点集合”不是路径端点集合。
- 有负环时最短路问题不正常。

**代表训练题与参考要点**

题：写出 Floyd 的核心不变量。

要点：第 k 轮结束后，$d[i][j]$ 等于从 $v_i$ 到 $v_j$ 且中间点只允许来自 $\{v_1,\ldots,v_k\}$ 的最短路长度。

### 套路 16.3：算法限制与反例

**题型信号**

- 问 “why Dijkstra fails with negative edges?”
- 问最长路能否类似最短路贪心。

**第一反应**

指出贪心不变量被破坏：已选点的距离可能被后续负边改小。

**标准答题步骤**

1. 说明 Dijkstra 依赖非负权。
2. 给出负边会让后选路径变短的机制。
3. 若要求反例，构造源点到 u 先有较短估计，但经另一个未确定点和负边可更短。
4. 最长路不能直接把 min 改 max，因为一般图最长简单路不满足同样最优子结构，且可能涉及 NP-hard 问题。

**可改编方式**

- 判断某带权图是否可用 Dijkstra。
- 问 Floyd 是否能处理负权边。
- 问负权环的影响。

**易错点**

- “有负权边”不等于“一定有负环”；Floyd 可处理负权边但不能有负环。
- Dijkstra 失败原因不是“算得慢”，而是正确性不变量失效。

**代表训练题与参考要点**

题：为什么最长路不能直接用“每轮选当前最大距离”的 Dijkstra 变体？

要点：最短路在非负权下有安全的贪心选择；最长简单路可能因为先选局部最大导致无法访问后续更优结构，且一般图中最长简单路没有这种贪心安全性。

## Problem Set 17：二部图与匹配

### 套路 17.1：二部图 $\lfloor n^2/4\rfloor$ 上界

**题型信号**

- n 个顶点的二部图最多多少条边。
- 出现 Mantel 型结论或 complete bipartite maximum。

**第一反应**

若左右两侧大小为 a,b，则边数最多 $ab$，且 $a+b=n$ 时乘积最大在两侧尽量平均。

**标准答题步骤**

1. 设二部划分大小为 a 与 b。
2. 二部图边只跨左右两侧，所以 $\lvert E\rvert\le ab$。
3. 在 $a+b=n$ 下，$ab\le \lfloor n^2/4\rfloor$。
4. 等号由 $K_{\lfloor n/2\rfloor,\lceil n/2\rceil}$ 取得。

**可改编方式**

- 证明无三角形图的边数上界（若课程涉及）。
- 给顶点数构造最大边二部图。

**易错点**

- 上界不是 $C(n,2)$，因为同侧不能有边。
- 两侧越平均乘积越大。

**代表训练题与参考要点**

题：8 个顶点的二部图最多多少条边？

要点：两侧各 4 个点时最大，边数 $4*4=16$。

---

### 套路 17.2：Hall 条件

**题型信号**

- “每个人分配一个不同任务”“system of distinct representatives”“左侧完全匹配”。
- 问是否存在覆盖某一侧的匹配。

**第一反应**

Hall：要覆盖左侧 X，检查任意 $S\subseteq X$ 的邻居集合 $N(S)$ 是否至少有 $\lvert S\rvert$ 个。

**标准答题步骤**

1. 明确左侧 X、右侧 Y、边的含义。
2. 写出 Hall 条件。
3. 证明存在：对任意 $S\subseteq X$ 证明 $\lvert N(S)\rvert\ge \lvert S\rvert$。
4. 否证存在：找一个具体 $S$ 使 $\lvert N(S)\rvert<\lvert S\rvert$。

**可改编方式**

- 课程-学生、工人-工作、集合代表元。
- 从邻接表检查完美匹配。
- 用 Hall 证明正则二部图有完美匹配。

**易错点**

- 只检查单个点不够。
- Hall 条件方向要看“覆盖哪一侧”。
- 完美匹配覆盖两侧所有点通常要求左右大小相等；左侧完全匹配只覆盖指定侧。

**代表训练题与参考要点**

题：左侧 ${a,b,c}$，邻居 $N(a)={1}$，$N(b)={1}$，$N(c)={2,3}$，是否存在覆盖左侧的匹配？

要点：取 $S={a,b}$，$N(S)={1}$，大小 1<2，违反 Hall，无覆盖左侧的匹配。

---

### 套路 17.3：交错路、增广路翻转

**题型信号**

- 给定匹配 M，问是否最大。
- 要求找 augmenting path 或 improve matching。

**第一反应**

从未匹配点出发，沿“不在 M / 在 M / 不在 M ...”交替找路，到未匹配点结束就是增广路。

**标准答题步骤**

1. 标出匹配边 M。
2. 找未匹配顶点。
3. 从未匹配顶点开始走非匹配边，再走匹配边，交替进行。
4. 若到达另一未匹配顶点，得到增广路。
5. 翻转：非匹配边加入，匹配边删除，匹配数 +1。

**可改编方式**

- 要求证明当前匹配不是最大。
- 要求执行一轮或多轮增广。
- 要求用 Berge 定理表述：无增广路 iff 匹配最大。

**易错点**

- 增广路首尾必须是未匹配点。
- 翻转后仍需检查每个顶点最多关联一条匹配边。

**代表训练题与参考要点**

题：为什么存在增广路说明匹配不是最大？

要点：增广路上非匹配边比匹配边多 1。翻转后仍是匹配，且边数增加 1，所以原匹配不是最大。

---

### 套路 17.4：应用建模

**题型信号**

- 人和任务、课程和教室、学生和项目、棋盘格覆盖、代表选择。
- “能否安排/分配/选择不同的……”

**第一反应**

把两个类别放左右两侧，用边表示“可选/可分配/兼容”。目标通常是匹配。

**标准答题步骤**

1. 定义左侧点集和右侧点集。
2. 定义边：什么时候连边。
3. 说明目标：最大匹配、完美匹配或覆盖左侧匹配。
4. 用 Hall、增广路或算法判断。
5. 把匹配结果翻译回原问题。

**可改编方式**

- 覆盖左侧但右侧可剩余。
- 一对多分配需要拆点或容量建模。
- 棋盘黑白染色后用匹配表示多米诺覆盖。

**易错点**

- 左右侧定义不清导致 Hall 条件方向错。
- 边的含义没写，模型不得分。

**代表训练题与参考要点**

题：有 4 名学生和 5 个项目，每个学生列出可做项目，问能否每人分配不同项目。

要点：左侧为学生，右侧为项目；学生与可做项目连边；目标是覆盖学生侧的匹配；用 Hall 检查任意学生子集的可选项目数是否不少于学生数。

## Problem Set 18：树与最小生成树

### 套路 18.1：树等价命题

**题型信号**

- 证明图是树。
- 出现连通、无圈、$n-1$ 条边、唯一通路、删边/加边性质。

**第一反应**

树题优先选最短等价路径：已知什么就用什么。

**标准答题步骤**

常用等价命题：

- 连通且无圈。
- 连通且有 $n-1$ 条边。
- 无圈且有 $n-1$ 条边。
- 任意两点间唯一简单通路。
- 连通且每条边都是桥。
- 无圈且加任意非边都会产生唯一圈。

**可改编方式**

- 用归纳证明树有 $n-1$ 条边。
- 从唯一通路推出无圈和连通。
- 证明树中至少有两个叶子。

**易错点**

- 使用等价命题前要确认课程已讲或先证明。
- “无圈”加“边数 n-1”才足以推出树；单独无圈不一定连通。

**代表训练题与参考要点**

题：证明若一个 n 顶点简单图连通且有 $n-1$ 条边，则它是树。

要点：若有圈，删除圈上一条边仍连通；可不断删圈边直到无圈且仍连通，得到一棵生成树。但 n 顶点树有 $n-1$ 条边，原图已经只有 $n-1$ 条，不能删边，故无圈，是树。

---

### 套路 18.2：树度数列构造

**题型信号**

- 给一串正整数，问是否为某棵树的度数列。
- 要求构造树。

**第一反应**

先查总和：n 个顶点树度数和必须是 $2(n-1)$。

**标准答题步骤**

1. 检查每个度数至少 1（n>1 的树无孤立点）。
2. 检查总和是否为 $2(n-1)$。
3. 若要构造：可用叶子逐步挂到高阶顶点，或用 Prüfer 序列思想。
4. 构造后检查各点度数。

**可改编方式**

- 证明有 $n_i$ 个度为 i 的点时满足某公式。
- 给叶子数和内部点度数求未知量。
- 构造指定叶子数的树。

**易错点**

- 总和条件对正整数序列通常足以构造树，但考试若要求构造必须画/列边。
- 不能出现 0 度点（除非 n=1）。

**代表训练题与参考要点**

题：序列 $(3,2,1,1,1)$ 是否是树度数列？

要点：n=5，总和 8，等于 $2(n-1)=8$，且均为正。可构造：令 A 度 3 连接 B,C,D，B 度 2 再连接 E，则度数为 3,2,1,1,1。

---

### 套路 18.3：Kruskal / Prim 过程题

**题型信号**

- 带权连通图，要求 MST、选边顺序、总权值。
- 指定用 Kruskal 或 Prim。

**第一反应**

过程分是关键：列边、排序、选/跳过原因、总权。

**标准答题步骤**

- Kruskal：
  1. 按权从小到大排序。
  2. 依次考虑边，不成圈则选，成圈则跳过。
  3. 选到 $n-1$ 条边停止。
- Prim：
  1. 从指定起点或任意点开始。
  2. 每轮选跨越已选点集与未选点集的最小边。
  3. 加入新顶点，直到覆盖所有顶点。

**可改编方式**

- 同权边导致多棵 MST。
- 要求比较 Kruskal 和 Prim 选边顺序。
- 给局部步骤问下一条选哪条。

**易错点**

- Kruskal 跳过成圈边，不是跳过同权边。
- Prim 只能选跨割边，不能选已选点集内部边。
- MST 边数必须是 $n-1$。

**代表训练题与参考要点**

题：Kruskal 中为什么选边不能形成圈？

要点：生成树必须无圈。若加入边形成圈，则该边两端已通过已选边连通，加入它不会帮助连通新顶点，只会破坏树结构。

---

### 套路 18.4：MST 割性质、环性质、交换论证

**题型信号**

- “证明这条边一定可以选/不能选”。
- “justify Kruskal/Prim”。
- “edge is in every/some/no MST”。

**第一反应**

不要只说“算法如此”。用割性质、环性质或交换论证。

**标准答题步骤**

- 割性质：某割上的轻边可安全加入某棵 MST；若严格最轻，通常在所有 MST 中。
- 环性质：某环上的严格最大边不在任何 MST 中。
- 交换论证：假设 MST T 不含安全边 e；加入 e 形成环；删去环中另一条不更轻的边，仍为生成树且权不增。

**可改编方式**

- 证明 Kruskal 每一步安全。
- 证明 Prim 每一步安全。
- 判断某条同权边是否一定在所有 MST。

**易错点**

- “最小边”要说明是哪个割上的最小边。
- “最大边不在 MST”要求严格最大；有并列时结论要弱化。
- “在某棵 MST 中”和“在所有 MST 中”区别很大。

**代表训练题与参考要点**

题：证明 Prim 每次选择的跨割最小边是安全的。

要点：当前已选顶点集 S 与外部形成割。Prim 选的是跨该割的最小边。由割性质，该边可以加入某棵 MST，不会破坏最优性，因此安全。

---

### 套路 18.5：次小生成树

**题型信号**

- second-best MST、次小生成树。
- 已知一棵 MST，要求找下一优生成树。

**第一反应**

枚举非树边：加进去形成唯一环，删环上除新边外的最大边。

**标准答题步骤**

1. 先求一棵 MST T，记权值 W。
2. 对每条非树边 e，加入 T 得到唯一环 C。
3. 在 C 中删除除 e 外权值最大的边 f，得到候选树。
4. 候选权值为 $W + w(e) - w(f)$。
5. 在所有大于或不小于 W 的候选中按题目口径取最小。

**可改编方式**

- 区分“严格次小”与“另一棵同权 MST”。
- 要求证明枚举非树边足够。
- 同权边导致多个候选。

**易错点**

- 删除的边不能是刚加入的 e，否则回到原树。
- 次小是否允许等于 MST 权值要看题目。
- 若 MST 不唯一，严格次小要排除同权生成树。

**代表训练题与参考要点**

题：为什么加入一条非树边会形成唯一环？

要点：MST 是树，树中任意两点间有唯一简单路径。非树边 e 连接的两个端点在树中已有唯一通路，加上 e 后这条通路与 e 组成唯一环。

## 最值得反复练的 8 个迁移模板

1. **度数/边数题**：握手定理 + 平均度 + 奇偶性。
2. **补图/自补图题**：$n-1-d$ + 总边数一半 + $n\equiv 0/1 \pmod{4}$。
3. **同构题**：先不变量否证；若证明则写双射和邻接保持。
4. **连通性题**：删点/删边后分支变化 + 不连通最大边数反证。
5. **Euler/Hamilton 题**：Euler 看连通与奇度；Hamilton 分构造、充分条件、必要条件否证。
6. **最短路算法题**：Dijkstra 表格 + Floyd 矩阵 + 不变量。
7. **匹配题**：二部建模 + Hall 条件 + 增广路翻转。
8. **MST 题**：Kruskal/Prim 过程 + 割性质/环性质/交换论证 + 非树边枚举次小 MST。
