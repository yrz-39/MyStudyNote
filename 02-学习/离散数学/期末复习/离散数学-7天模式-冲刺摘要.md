## 3. 高频判定表

| 关键词 | 第一反应 | 必查条件 |
|---|---|---|
| 度数、边数 | 握手定理 | $\sum deg=2\lvert E\rvert$，奇度点偶数个 |
| 补图 | 原边/非边互换 | $\deg_{\bar G}(v)=n-1-\deg_G(v)$，边数互补 |

| 连通 | 任意两点有路 | 分支数、路径构造 |
| 桥 | 删边 | 连通分支数增加 |
| 割点 | 删点及关联边 | 连通分支数增加 |
| Euler | 走边 | 非零度顶点连通；奇度点 0/2 |
| Hamilton | 走点 | 构造；Dirac/Ore；割点/二部数量否证 |
| 二部图 | 二染色 | 等价于无奇圈 |

| 树 | 连通无圈 | $n-1$ 边、唯一通路、桥 |

| 偏序 | 自反+反对称+传递 | 哈斯图删自环和传递边 |
| 等价关系 | 自反+对称+传递 | 等价类、商集 |

## 4. 图论证明入口速查

### PS13：度数 / 补图 / 同构

- [ ] **奇度顶点偶数**：握手定理 → 度数和偶数 → 奇数个奇数相加为奇数，矛盾。
- [ ] **存在高/低度顶点**：平均度 $2m/n$ → 反证所有点都低/高。
- [ ] **补图度数**：同一顶点集，潜在邻居 $n-1$，补图取剩余邻居。
- [ ] **自补图必要条件**：$G\cong \bar G$ → 边数相等 → $n(n-1)/4$ 整数。
- [ ] **证明同构**：写 $f$，验证 $uv\in E \iff f(u)f(v)\in E$。
- [ ] **否证同构**：顶点数、边数、度序列、三角形数、连通分支、桥/割点、特殊顶点邻接。

### PS14：连通性

- [ ] **边数推出连通**：反证不连通 → 最多 $K_{n-1}+孤立点$ → $C(n-1,2)$。
- [ ] **桥**：删边后分支数增加。
- [ ] **割点**：删点及关联边后分支数增加。
- [ ] **k 点连通**：任删少于 k 个点仍连通；否证找点割。
- [ ] **k 边连通**：任删少于 k 条边仍连通；否证找边割。

### PS15：Euler / Hamilton / 线图

- [ ] **Euler 回路**：连通 + 全偶度。
- [ ] **Euler 通路**：连通 + 奇度点 0 或 2；非回路通常恰 2。
- [ ] **$K_{m,n}$ Euler**：左度 n，右度 m；按奇偶数奇度点。
- [ ] **$K_{m,n}$ Hamilton 回路**：左右交替，需 $m=n\ge 2$。
- [ ] **Dirac**：$n\ge 3$ 且 $\delta\ge n/2$ → Hamilton。
- [ ] **Ore**：任意不相邻 $u,v$ 有 $d(u)+d(v)\ge n$ → Hamilton。
- [ ] **Hamilton 否证**：割点、非 2-连通、二部两侧不等、删点后分支过多。
- [ ] **线图**：原图边变线图点；原图边共享端点则线图点相邻。

### PS17：匹配

- [ ] **二部图极值**：左右 a,b，$\lvert E\rvert\le ab\le \lfloor n^2/4\rfloor$。
- [ ] **Hall**：覆盖左侧 X iff 任意 $S\subseteq X$，$\lvert N(S)\rvert\ge \lvert S\rvert$。
- [ ] **增广路**：未匹配点到未匹配点，边交替；翻转后匹配数 +1。
- [ ] **应用建模**：左侧对象、右侧对象、边含义、目标匹配类型。

### PS18：树 / MST

- [ ] **树等价**：连通无圈 ⇔ 连通且 $n-1$ 边 ⇔ 无圈且 $n-1$ 边 ⇔ 唯一简单通路。
- [ ] **树度数列**：$\sum d_i=2(n-1)$；构造后回查度数。
- [ ] **环性质**：环上严格最大边不在任何 MST。
- [ ] **割性质**：割上最小边可安全加入某棵 MST；严格最小常在所有 MST。
- [ ] **交换论证**：加安全边成环，删另一条不更轻边，总权不增。
- [ ] **次小 MST**：非树边 e 加入成唯一环，删除 e 外最大边，候选权 $W+w(e)-w(f)$。

## 5. 算法表格速查

| 算法 | 用途 | 表格/步骤 | 正确性关键词 | 限制/陷阱 |
|---|---|---|---|---|
| Dijkstra | 非负权单源最短路 | S、选点、距离估计、前驱 | 每次选入 S 的点距离已最终确定 | 普通版不能直接有负权边 |
| Floyd | 全源最短路 | 初始矩阵；逐 k 更新 $d_{ij}=\min(d_{ij},d_{ik}+d_{kj})$ | 第 k 轮中间点只允许前 k 个点 | 无边是 $\infty$；负环会破坏最短路 |
| Warshall | 关系传递闭包 | 布尔矩阵 $w_{ij}=w_{ij}\lor(w_{ik}\land w_{kj})$ | 第 k 轮允许第 k 个点作中间点 | 传递闭包要迭代到所有可达对 |
| Kruskal | MST | 边按权排序；不成圈则选；选 $n-1$ 条 | 割性质/环性质 | 同权可多解；不能成圈 |
| Prim | MST | 从点集出发；每轮选跨割最小边 | 割性质 | 只能选跨割边 |
| Huffman | 最优前缀码 | 每轮合并两个最小权，放回 | 贪心合并最小权 | 合并后要重新排序；码字不能互为前缀 |

## 6. 第 1-10 讲保分模板

### 逻辑 / 谓词

- [ ] “所有 A 都 B”：$\forall x(A(x)\to B(x))$，不是 $A(x)\land B(x)$。
- [ ] “存在 A 是 B”：$\exists x(A(x)\land B(x))$。
- [ ] 否定：$\neg \forall x P(x) \equiv \exists x \neg P(x)$；$\neg \exists x P(x) \equiv \forall x \neg P(x)$。
- [ ] 唯一存在：存在 + 任意两个满足者相等。

### 集合

- [ ] 证明 $A=B$：证 $A\subseteq B$ 和 $B\subseteq A$。
- [ ] 任取元素 x，展开 $\in$、$\cup$、$\cap$、差集、补集定义。
- [ ] 幂集：$\lvert P(A)\rvert=2^{\lvert A\rvert}$；注意 $\in$ vs $\subseteq$。

### 关系 / 等价关系

- [ ] 逆关系、复合关系注意顺序。
- [ ] 等价关系三步：自反、对称、传递。
- [ ] 等价类写成集合，不只写代表元。

### 函数

- [ ] 单射：设 $f(a)=f(b)$，推出 $a=b$。
- [ ] 满射：任取陪域 $y$，构造定义域 $x$ 使 $f(x)=y$。
- [ ] 双射：单射 + 满射；可构造逆函数。

### 基数 / 可数性

- [ ] 可数：给列举、编码、双射/注入；不能只说“无限”。
- [ ] $Z$ 可数：$0,1,-1,2,-2,...$。
- [ ] 有限多个可数集并仍可数。
- [ ] 不可数常用 Cantor 对角线或幂集严格更大。

### 归纳

- [ ] 写清 $P(n)$。
- [ ] 基础步。
- [ ] 归纳假设。
- [ ] 归纳步。
- [ ] 结论。
- [ ] 强归纳假设 $P(n0)...P(k)$ 全部成立。

### 数论

- [ ] $a|b$：存在整数 k，使 $b=ak$。
- [ ] 互素：$\gcd(a,b)=1$。
- [ ] 同余：$a\equiv b \pmod{m}$ iff $m \mid (a-b)$。
- [ ] 无理性反证：假设最简分数 → 推出分子分母有公因子 → 矛盾。

## 7. 高频陷阱清单

- [ ] Euler 走边；Hamilton 走点。
- [ ] Hamilton 没有像 Euler 那样的简单充要条件；Dirac/Ore 是充分条件。
- [ ] Dijkstra 普通版要求非负权。
- [ ] Floyd 矩阵中无边填 $\infty$，不是 0；对角线才是 0。
- [ ] Hall 要检查任意左侧子集，不只单点。
- [ ] 最大匹配不等于完美匹配；极大匹配不等于最大匹配。
- [ ] MST 不一定唯一；“某棵 MST”与“所有 MST”分清。
- [ ] 环性质要求“严格最大边”才能断言不在任何 MST。
- [ ] 同构必须写映射并验证邻接；度序列相同不是充分条件。
- [ ] 补图公式是 $n-1-d$。
- [ ] 反对称允许自环；不对称不允许自环。
- [ ] 极大元可多个；最大元若存在则唯一。
- [ ] 哈斯图要删自环和传递边。
- [ ] lub/glb 先列所有上界/下界，再找最小/最大。
- [ ] $\forall x(A\to B)$ 不要写成 $\forall x(A\land B)$。
- [ ] 集合等式不要只证一边。
- [ ] 函数满射要从陪域任意 y 出发构造 x。
- [ ] 可数性不要写“无限所以可数”。
- [ ] 归纳证明不要偷用待证结论。
- [ ] 整除证明要写“存在整数”。
