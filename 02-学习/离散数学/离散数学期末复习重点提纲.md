# 第一部分：逻辑与证明

## 第 1 讲：命题逻辑初步

### 1. 命题与真值

- **命题**：能够判断真假的陈述句。
- 非命题常见类型：
  - 疑问句、祈使句、感叹句；
  - 含未赋值变量且无法判定真假的语句；
  - 自指悖论类语句。
- **命题变元**：真值可变的命题，常记为 `p, q, r`。
- 古典二值逻辑中，真值只有：
  - `T`：真；
  - `F`：假。

### 2. 五个基本命题联结词

| 联结词 | 符号 | 读法 | 为真的条件 |
|---|---|---|---|
| 否定 | `¬p` | 非 p | p 假 |
| 合取 | `p ∧ q` | p 且 q | p、q 都真 |
| 析取 | `p ∨ q` | p 或 q | 至少一个真 |
| 蕴涵 | `p → q` | 若 p 则 q | 只有 p 真 q 假时为假 |
| 双蕴涵 | `p ↔ q` | p 当且仅当 q | p、q 真值相同 |

### 3. 蕴涵的重点

- `p → q` 等价于 `¬p ∨ q`。
- `p → q` 等价于其逆否命题 `¬q → ¬p`。
- 但不等价于：
  - 逆命题：`q → p`
  - 否命题：`¬p → ¬q`

### 4. 命题公式与优先级

命题表达式由命题变元和联结词递归构成。

常见优先级：

```text
¬  >  ∧  >  ∨  >  →  >  ↔
```

### 5. 自然语言形式化

步骤：

1. 找出原子命题。
2. 给每个原子命题设变元。
3. 分析“并且、或者、如果……那么、当且仅当、除非、只有”等逻辑关系。
4. 写成命题公式。

常见翻译：

| 自然语言 | 逻辑形式 |
|---|---|
| 如果 A，那么 B | `A → B` |
| 只有 B，才 A | `A → B` |
| A 仅当 B | `A → B` |
| A 当且仅当 B | `A ↔ B` |
| A 除非 B | `¬B → A`，也可写 `A ∨ B` |
| A 是 B 的充分条件 | `A → B` |
| A 是 B 的必要条件 | `B → A` |

### 6. 永真式、矛盾式、可能式

- **永真式/重言式**：所有赋值下都为真，如 `p ∨ ¬p`。
- **矛盾式/永假式**：所有赋值下都为假，如 `p ∧ ¬p`。
- **可能式/可满足式**：至少存在一种赋值为真。

### 7. 常用逻辑等价式

| 名称 | 等价式 |
|---|---|
| 双重否定律 | `¬¬p ≡ p` |
| 幂等律 | `p ∧ p ≡ p`，`p ∨ p ≡ p` |
| 交换律 | `p ∧ q ≡ q ∧ p`，`p ∨ q ≡ q ∨ p` |
| 结合律 | `(p ∧ q) ∧ r ≡ p ∧ (q ∧ r)` |
| 分配律 | `p ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)` |
| 德摩根律 | `¬(p ∧ q) ≡ ¬p ∨ ¬q`；`¬(p ∨ q) ≡ ¬p ∧ ¬q` |
| 蕴涵等值 | `p → q ≡ ¬p ∨ q` |
| 假言易位 | `p → q ≡ ¬q → ¬p` |
| 双蕴涵 | `p ↔ q ≡ (p → q) ∧ (q → p)` |
| 排中律 | `p ∨ ¬p ≡ T` |
| 矛盾律 | `p ∧ ¬p ≡ F` |
| 吸收律 | `p ∨ (p ∧ q) ≡ p`；`p ∧ (p ∨ q) ≡ p` |

### 8. 范式

- **文字**：命题变元或其否定，如 `p`、`¬p`。
- **简单析取式**：若干文字的析取。
- **简单合取式**：若干文字的合取。
- **析取范式 DNF**：若干简单合取式的析取。
- **合取范式 CNF**：若干简单析取式的合取。

任意命题公式都可化为与之等价的析取范式和合取范式。

化范式步骤：

1. 消去 `→` 和 `↔`。
2. 用双重否定律与德摩根律将 `¬` 内移。
3. 用分配律整理成 DNF 或 CNF。

### 9. 命题逻辑可判定性

- 简单析取式是永真式，当且仅当它同时含有某变元和其否定。
- 简单合取式是矛盾式，当且仅当它同时含有某变元和其否定。
- DNF 是矛盾式，当且仅当每个简单合取式都是矛盾式。
- CNF 是永真式，当且仅当每个简单析取式都是永真式。

## 第 2 讲：命题逻辑的推理理论

### 1. 三种推理方式

| 类型 | 思路 | 常见场景 |
|---|---|---|
| 归纳推理 | 从大量现象总结规律 | 经验科学 |
| 演绎推理 | 从规则和前提出结论 | 数学证明 |
| 溯因推理 | 从结论反推可能原因 | 诊断、侦查 |

数学主要使用 **演绎推理**。

### 2. 语义蕴含与语法推导

- `P ⊨ Q`：语义蕴含，只要 P 真，Q 必真。
- `P ⊢ Q`：语法推导，可通过推理规则从 P 推出 Q。
- 可靠性：`P ⊢ Q ⇒ P ⊨ Q`。
- 完备性：`P ⊨ Q ⇒ P ⊢ Q`。

### 3. 常用推理规则

| 名称 | 形式 |
|---|---|
| 分离规则 MP | `p, p → q ⟹ q` |
| 拒取式 MT | `¬q, p → q ⟹ ¬p` |
| 假言三段论 | `p → q, q → r ⟹ p → r` |
| 析取三段论 | `p ∨ q, ¬p ⟹ q` |
| 合取引入 | `p, q ⟹ p ∧ q` |
| 化简 | `p ∧ q ⟹ p` |
| 附加 | `p ⟹ p ∨ q` |
| 归结 | `p ∨ q, ¬p ∨ r ⟹ q ∨ r` |

### 4. 用命题逻辑证明实际问题

标准流程：

1. 设命题变元。
2. 把每个前提翻译成命题公式。
3. 把目标结论翻译成命题公式。
4. 用推理规则或等值演算推出结论。

## 第 3 讲：谓词逻辑引论

### 1. 为什么引入谓词逻辑

命题逻辑把整句话当作最小单位，无法表达“对象、属性、关系、数量范围”。

例如：

- “所有学生都学过微积分”
- “存在一个素数在 n 和 2n 之间”

需要谓词和量词。

### 2. 谓词

- **谓词**：带变量的命题函数，如 `P(x)`、`R(x, y)`。
- 给变量赋具体值后，谓词变为命题。
- 变量取值范围称为 **论域**。

### 3. 量词

| 量词 | 符号 | 含义 |
|---|---|---|
| 全称量词 | `∀x P(x)` | 对所有 x，P(x) 成立 |
| 存在量词 | `∃x P(x)` | 存在至少一个 x，使 P(x) 成立 |

### 4. 量词否定

非常重要：

```text
¬∀x P(x) ≡ ∃x ¬P(x)
¬∃x P(x) ≡ ∀x ¬P(x)
```

多重量词否定时，逐层取反并交换量词：

```text
¬∀x∃y P(x, y) ≡ ∃x∀y ¬P(x, y)
```

### 5. 量词顺序

一般不可交换：

```text
∀x∃y P(x, y)
```

表示“每个 x 都有某个 y”。

```text
∃y∀x P(x, y)
```

表示“存在同一个 y 对所有 x 都适用”。

第二个通常更强。

### 6. 谓词逻辑推理规则

| 名称 | 形式 | 注意 |
|---|---|---|
| 全称例化 UI | `∀x P(x) ⟹ P(a)` | a 为论域中任意元素 |
| 全称推广 UG | 对任意 a 证明 `P(a)`，得 `∀x P(x)` | a 不能有特殊性 |
| 存在例化 EI | `∃x P(x) ⟹ P(c)` | c 是新引入的对象 |
| 存在推广 EG | `P(a) ⟹ ∃x P(x)` | 由一个例子推出存在 |

## 第 4 讲：证明方法概论

### 1. 数学证明的基本结构

要证明命题：

```text
A → B
```

其中 A 是前提，B 是结论。

### 2. 直接证明

从 A 出发，通过定义、已知定理、逻辑推理推出 B。

适用于：
- 整除问题；
- 集合包含；
- 不等式；
- 基本性质证明。

### 3. 逆否证明

证明：

```text
A → B
```

可转化为证明：

```text
¬B → ¬A
```

适用于：
- “若 n² 为偶数，则 n 为偶数”；
- 结论的否定更容易使用时。

### 4. 反证法

假设 A 成立且 B 不成立，即：

```text
A ∧ ¬B
```

推出矛盾，从而 B 成立。

适用于：
- 无穷性证明；
- 不存在性证明；
- 根号 2 无理性；
- 图论中否定假设更容易引出矛盾的问题。

### 5. 分类讨论

若前提可分为若干情形：

```text
A1 ∨ A2 ∨ ... ∨ Ak
```

分别证明每种情形下 B 成立。

### 6. 构造性证明

要证明“存在某对象满足性质”，直接构造出对象。

### 7. 非构造性证明

证明对象存在，但不明确给出具体对象。

### 8. 反例证明

要证明全称命题为假，只需找一个反例：

```text
¬∀x P(x) ≡ ∃x ¬P(x)
```

### 9. 空证明与平凡证明

- 空证明：前提 A 本身不可能成立，则 `A → B` 永真。
- 平凡证明：结论 B 本身恒真，则 `A → B` 永真。

# 第二部分：集合、关系、函数与基数

## 第 5 讲：集合论导引

### 1. 集合基本概念

- `x ∈ A`：x 是 A 的元素。
- `A ⊆ B`：A 的每个元素都属于 B。
- `A = B` 当且仅当 `A ⊆ B` 且 `B ⊆ A`。
- 空集 `∅` 是任意集合的子集。
- 幂集 `P(A)`：A 的所有子集构成的集合。
- 若 `|A| = n`，则 `|P(A)| = 2^n`。

### 2. 集合运算

| 运算 | 符号 | 含义 |
|---|---|---|
| 并 | `A ∪ B` | 属于 A 或 B |
| 交 | `A ∩ B` | 同时属于 A 和 B |
| 差 | `A - B` | 属于 A 且不属于 B |
| 补 | `Ā` | 不属于 A |
| 对称差 | `A ⊕ B` | 属于 A 或 B 但不同时属于二者 |

对称差重点：

```text
A ⊕ B = (A - B) ∪ (B - A)
      = (A ∪ B) - (A ∩ B)
```

### 3. 常用集合恒等式

| 名称 | 恒等式 |
|---|---|
| 交换律 | `A ∪ B = B ∪ A`，`A ∩ B = B ∩ A` |
| 结合律 | `(A ∪ B) ∪ C = A ∪ (B ∪ C)` |
| 分配律 | `A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)` |
| 德摩根律 | `¬(A ∪ B) = ¬A ∩ ¬B`，`¬(A ∩ B) = ¬A ∪ ¬B` |
| 吸收律 | `A ∪ (A ∩ B) = A`，`A ∩ (A ∪ B) = A` |
| 幂等律 | `A ∪ A = A`，`A ∩ A = A` |
| 空集律 | `A ∪ ∅ = A`，`A ∩ ∅ = ∅` |
| 全集律 | `A ∪ U = U`，`A ∩ U = A` |

### 4. 集合证明方法

1. **元素追踪法**：任取 `x`，证明 `x ∈ A ⇔ x ∈ B`。
2. **双包含法**：证明 `A ⊆ B` 和 `B ⊆ A`。
3. **逻辑等值演算法**：把集合关系转化为谓词逻辑。
4. **Venn 图辅助理解**：不建议作为严格证明的唯一依据。
5. **循环证明**：证明多个命题等价时，可证 `P1 ⇒ P2 ⇒ ... ⇒ P1`。

### 5. 充分必要条件

- P 是 Q 的充分条件：`P → Q`。
- P 是 Q 的必要条件：`Q → P`。
- P 是 Q 的充要条件：`P ↔ Q`。

证明“P 当且仅当 Q”必须证明两个方向：

```text
P → Q
Q → P
```

## 第 6 讲：二元关系

### 1. 有序对与笛卡尔积

- 有序对 `(a, b)` 强调顺序。
- `(a, b) = (c, d)` 当且仅当 `a = c` 且 `b = d`。
- 笛卡尔积：

```text
A × B = {(a, b) | a ∈ A 且 b ∈ B}
```

若 `|A| = m, |B| = n`，则：

```text
|A × B| = mn
```

### 2. 二元关系

设 `A, B` 为集合，若：

```text
R ⊆ A × B
```

则 R 是从 A 到 B 的二元关系。

若 `R ⊆ A × A`，称 R 是 A 上的关系。

### 3. 定义域、值域、域

对 `R ⊆ A × B`：

```text
Dom(R) = {x ∈ A | ∃y ∈ B, (x, y) ∈ R}
Ran(R) = {y ∈ B | ∃x ∈ A, (x, y) ∈ R}
Field(R) = Dom(R) ∪ Ran(R)
```

### 4. 关系的表示

- 集合表示；
- 关系矩阵；
- 有向图。

### 5. 逆关系

```text
R^{-1} = {(b, a) | (a, b) ∈ R}
```

### 6. 关系复合

若 `S ⊆ A × B`，`R ⊆ B × C`，则：

```text
R ∘ S = {(a, c) | ∃b ∈ B, (a, b) ∈ S 且 (b, c) ∈ R}
```

注意顺序：通常右边的关系先作用。

### 7. 关系的幂

设 `R ⊆ A × A`：

```text
R^1 = R
R^{n+1} = R^n ∘ R
```

在关系图中，`R^n` 表示长度为 n 的通路可达关系。

## 第 7 讲：函数

### 1. 函数的集合定义

函数是特殊的关系。`f: A → B` 满足：

1. 对每个 `a ∈ A`，存在 `b ∈ B` 使 `f(a)=b`。
2. 对每个 `a ∈ A`，对应的 `b` 唯一。

即：

```text
∀a∈A ∃!b∈B, (a,b)∈f
```

### 2. 定义域、陪域、值域

- 定义域：A。
- 陪域：B。
- 值域/像集：

```text
Ran(f) = {f(a) | a ∈ A}
```

注意：值域不一定等于陪域。

### 3. 单射、满射、双射

| 性质 | 定义 | 判断方式 |
|---|---|---|
| 单射 injection | `f(x)=f(y) ⇒ x=y` | 不同输入不会同像 |
| 满射 surjection | `∀b∈B, ∃a∈A, f(a)=b` | 每个陪域元素都被命中 |
| 双射 bijection | 既单射又满射 | 一一对应 |

有限集合中若 `|A| = |B|`：

```text
单射 ⇔ 满射 ⇔ 双射
```

### 4. 像与原像

设 `X ⊆ A, Y ⊆ B`：

```text
f(X) = {f(x) | x ∈ X}
f^{-1}(Y) = {x ∈ A | f(x) ∈ Y}
```

注意：`f^{-1}(Y)` 不要求 f 有反函数。

### 5. 函数复合

若 `f: A → B`，`g: B → C`：

```text
g ∘ f: A → C
(g ∘ f)(x) = g(f(x))
```

复合满足结合律：

```text
h ∘ (g ∘ f) = (h ∘ g) ∘ f
```

一般不满足交换律。

### 6. 反函数

`f: A → B` 有反函数当且仅当 f 是双射。

若 f 是双射：

```text
f^{-1}: B → A
f^{-1}(f(a)) = a
f(f^{-1}(b)) = b
```

## 第 8 讲：集合的基数

### 1. 等势

两个集合 A、B 等势，记作：

```text
A ≈ B
```

当且仅当存在双射 `f: A → B`。

### 2. 有限集、无限集、可列集

- 有限集：与 `{1,2,...,n}` 等势。
- 无限集：不是有限集。
- 可列无限集：与 `N` 等势。
- 可列集：有限集或可列无限集。

### 3. 常见可列集

```text
N ≈ Z ≈ Q ≈ N × N
```

复习要会解释：
- 整数可按 `0,1,-1,2,-2,...` 排列；
- 正有理数可用网格枚举；
- `N × N` 可用对角线法枚举。

### 4. 不可列集

实数集 `R` 不可列。

经典证明方法：**Cantor 对角线法**。

### 5. Cantor 定理

任意集合 A 都满足：

```text
|A| < |P(A)|
```

即不存在从 A 到其幂集 `P(A)` 的满射。

因此有无限层级：

```text
A ≺ P(A) ≺ P(P(A)) ≺ ...
```

### 6. 优势关系

- `A ≼ B`：存在从 A 到 B 的单射。
- `A ≺ B`：`A ≼ B` 且 `A` 与 `B` 不等势。

### 7. Cantor-Bernstein-Schröder 定理

若：

```text
A ≼ B 且 B ≼ A
```

则：

```text
A ≈ B
```

用途：难以直接构造双射时，可分别构造两个单射。

### 8. 重要结论速查

```text
N ≈ Z ≈ Q
R ≈ (0,1) ≈ [0,1]
P(N) ≈ R
N ≺ R
A ≺ P(A)
```

## 第 9 讲：数学归纳法与递归结构

### 1. 普通数学归纳法

证明对所有 `n ≥ n0`，命题 `P(n)` 成立：

1. 基础步：证明 `P(n0)`。
2. 归纳步：假设 `P(k)` 成立，证明 `P(k+1)` 成立。
3. 得出结论：`∀n ≥ n0, P(n)` 成立。

### 2. 强数学归纳法

归纳步中假设：

```text
P(n0), P(n0+1), ..., P(k)
```

全部成立，再证明 `P(k+1)`。

适用于：
- 递推式；
- 分解问题；
- 数论分解，如算术基本定理。

### 3. 良序原理

自然数任意非空子集都有最小元素。

常与归纳法等价使用。

### 4. 递归定义

递归定义通常包括：

1. 初始值；
2. 递推规则。

例如：

```text
a_0 = c
a_{n+1} = F(a_n)
```

### 5. 结构归纳法

用于递归定义的对象。

证明方式：

1. 证明初始对象满足性质。
2. 假设已有对象满足性质。
3. 证明通过生成规则得到的新对象仍满足性质。
4. 得出所有递归生成对象都满足性质。

适用于：
- 字符串；
- 树；
- 递归算法正确性；
- 公式结构证明。

# 第三部分：数论与代数基础

## 第 10 讲：数论初步

### 1. 整除

若存在整数 k，使：

```text
b = ak
```

则称 a 整除 b，记作：

```text
a | b
```

### 2. 带余除法

对 `a ∈ Z, d ∈ Z+`，存在唯一整数 q、r，使：

```text
a = dq + r, 0 ≤ r < d
```

其中：
- q 为商；
- r 为余数。

### 3. 同余

若：

```text
m | (a - b)
```

则称 a 与 b 模 m 同余，记作：

```text
a ≡ b (mod m)
```

等价地，a 与 b 除以 m 的余数相同。

### 4. 模运算性质

若：

```text
a ≡ b (mod m)
c ≡ d (mod m)
```

则：

```text
a + c ≡ b + d (mod m)
a - c ≡ b - d (mod m)
ac ≡ bd (mod m)
```

注意：模运算下除法不能随便做，除非有模逆元。

### 5. 素数与合数

- 素数：大于 1 且只有 1 和自身两个正因子的整数。
- 合数：大于 1 且不是素数。

若 n 是合数，则 n 有不超过 `√n` 的素因子。  
用处：判断 n 是否素数时只需试除到 `√n`。

### 6. 算术基本定理

每个大于 1 的整数都能唯一分解为素数乘积，忽略因子顺序：

```text
n = p_1^{a_1} p_2^{a_2} ... p_k^{a_k}
```

### 7. 最大公约数

```text
gcd(a,b)
```

表示 a 和 b 的最大正公约数。

若 `gcd(a,b)=1`，称 a 与 b 互素。

### 8. Euclid 辗转相除法

核心公式：

```text
gcd(a,b) = gcd(b, a mod b)
```

不断替换直到余数为 0。

### 9. Bézout 恒等式

若 `d = gcd(a,b)`，则存在整数 x, y，使：

```text
ax + by = d
```

特别地，若 `gcd(a,m)=1`，则存在 x，使：

```text
ax ≡ 1 (mod m)
```

此时 x 是 a 模 m 的逆元。

### 10. 线性同余方程

方程：

```text
ax ≡ b (mod m)
```

有解当且仅当：

```text
gcd(a,m) | b
```

若 `gcd(a,m)=1`，则唯一解模 m 存在，可用模逆元求。

### 11. 中国剩余定理 CRT

若 `m_1, ..., m_k` 两两互素，则同余方程组：

```text
x ≡ a_1 (mod m_1)
x ≡ a_2 (mod m_2)
...
x ≡ a_k (mod m_k)
```

模 `M = m_1m_2...m_k` 有唯一解。

### 12. Euler 函数

`φ(n)` 表示 1 到 n 中与 n 互素的正整数个数。

若：

```text
n = p_1^{a_1} ... p_k^{a_k}
```

则：

```text
φ(n) = n(1 - 1/p_1)...(1 - 1/p_k)
```

特别地：

```text
φ(p) = p - 1
φ(p^k) = p^k - p^{k-1}
```

### 13. Euler 定理

若 `gcd(a,n)=1`，则：

```text
a^{φ(n)} ≡ 1 (mod n)
```

### 14. Fermat 小定理

若 p 为素数且 `p ∤ a`，则：

```text
a^{p-1} ≡ 1 (mod p)
```

也可写：

```text
a^p ≡ a (mod p)
```

### 15. RSA 基础思想

- 选两个大素数 p, q。
- 令 `N = pq`。
- `φ(N) = (p-1)(q-1)`。
- 选 e 与 `φ(N)` 互素。
- 找 d，使：

```text
ed ≡ 1 (mod φ(N))
```

加密：

```text
c ≡ m^e (mod N)
```

解密：

```text
m ≡ c^d (mod N)
```

安全性依赖大整数分解困难。

# 第四部分：关系性质与偏序

## 第 11 讲：关系的性质

### 1. 五类重要关系性质

设 R 是 A 上的关系。

| 性质 | 定义 |
|---|---|
| 自反 | `∀a∈A, (a,a)∈R` |
| 反自反 | `∀a∈A, (a,a)∉R` |
| 对称 | `(a,b)∈R ⇒ (b,a)∈R` |
| 反对称 | `(a,b)∈R ∧ (b,a)∈R ⇒ a=b` |
| 传递 | `(a,b)∈R ∧ (b,c)∈R ⇒ (a,c)∈R` |

### 2. 用集合运算刻画性质

| 性质 | 等价条件 |
|---|---|
| 自反 | `I_A ⊆ R` |
| 反自反 | `R ∩ I_A = ∅` |
| 对称 | `R = R^{-1}` |
| 反对称 | `R ∩ R^{-1} ⊆ I_A` |
| 传递 | `R ∘ R ⊆ R` |

其中 `I_A = {(a,a) | a∈A}`。

### 3. 等价关系

R 是等价关系，当且仅当 R 同时满足：

1. 自反；
2. 对称；
3. 传递。

### 4. 等价类

若 R 是 A 上等价关系，对 `a∈A`：

```text
[a]_R = {x∈A | aRx}
```

性质：

- `a ∈ [a]`。
- 若 `aRb`，则 `[a] = [b]`。
- 若 `¬aRb`，则 `[a] ∩ [b] = ∅`。
- 所有等价类构成 A 的一个划分。

### 5. 商集

A 关于 R 的商集：

```text
A/R = {[a]_R | a∈A}
```

### 6. 等价关系与划分

重要对应：

```text
A 上的等价关系  ⇔  A 的划分
```

从等价关系可得到等价类划分；  
从划分可定义“在同一个块中”的等价关系。

### 7. 关系闭包

R 关于性质 P 的闭包，是包含 R 的、具有性质 P 的最小关系。

| 闭包 | 公式 |
|---|---|
| 自反闭包 | `r(R) = R ∪ I_A` |
| 对称闭包 | `s(R) = R ∪ R^{-1}` |
| 传递闭包 | `t(R) = R ∪ R^2 ∪ R^3 ∪ ...` |

若 `|A| = n`，则：

```text
t(R) = R ∪ R^2 ∪ ... ∪ R^n
```

### 8. Warshall 算法

用途：求关系矩阵的传递闭包。

思想：动态规划地判断 `i` 到 `j` 是否可经由前 k 个顶点连通。

复杂度：

```text
O(n^3)
```

## 第 12 讲：偏序关系

### 1. 偏序关系

非空集合 A 上的关系 `≼` 若满足：

1. 自反；
2. 反对称；
3. 传递；

则称为偏序关系。

`(A, ≼)` 称为偏序集。

### 2. 常见偏序

| 集合 | 偏序 |
|---|---|
| 数集 | `≤` |
| 幂集 `P(S)` | `⊆` |
| 正整数集 | 整除关系 `|` |

### 3. 可比与不可比

在偏序集 `(A, ≼)` 中：

- a 与 b 可比：`a≼b` 或 `b≼a`。
- 不可比：两者都不成立。

若任意两个元素都可比，则为 **全序/线序**。

### 4. Hasse 图

画 Hasse 图时：

1. 省略自环；
2. 省略由传递性推出的边；
3. 边方向默认向上，因此可省略箭头。

### 5. 特殊元素

| 名称 | 定义 |
|---|---|
| 极小元 | 没有其他元素严格小于它 |
| 极大元 | 没有其他元素严格大于它 |
| 最小元 | 小于等于所有元素 |
| 最大元 | 大于等于所有元素 |

注意：
- 最小元若存在则唯一。
- 最大元若存在则唯一。
- 极小元/极大元可以有多个。
- 最小元一定是极小元，但极小元不一定是最小元。

### 6. 上界、下界、最小上界、最大下界

对 `B ⊆ A`：

- 上界：`u` 满足 `∀b∈B, b≼u`。
- 下界：`l` 满足 `∀b∈B, l≼b`。
- 最小上界/上确界：所有上界中的最小者，记作 `lub` 或 `∨`。
- 最大下界/下确界：所有下界中的最大者，记作 `glb` 或 `∧`。

### 7. 格

偏序集若任意两个元素都有最小上界和最大下界，则称为格。

# 第五部分：图论

## 第 13 讲：图论导引

### 1. 图的基本定义

图通常由顶点集和边集构成：

```text
G = (V, E)
```

- 无向图：边无方向。
- 有向图：边有方向。
- 简单图：无自环、无重边。
- 多重图：允许重边。
- 伪图：允许自环。

### 2. 顶点度

无向图中顶点 v 的度 `d(v)`：与 v 关联的边数。  
自环对度贡献 2。

### 3. 握手定理

无向图：

```text
∑_{v∈V} d(v) = 2|E|
```

推论：

```text
奇度顶点数为偶数
```

平均度：

```text
2|E| / |V|
```

并有：

```text
δ(G) ≤ 2|E|/|V| ≤ Δ(G)
```

### 4. 简单图常用公式

n 阶简单图：

```text
最大边数 = C(n,2) = n(n-1)/2
最大度 ≤ n-1
```

完全图 `K_n`：

```text
|E(K_n)| = n(n-1)/2
每个顶点度 = n-1
```

完全二部图 `K_{m,n}`：

```text
|E| = mn
一侧顶点度为 n，另一侧顶点度为 m
```

### 5. 子图

- 子图：顶点和边都来自原图。
- 生成子图：包含原图全部顶点。
- 导出子图：由选定顶点及其在原图中所有相互连接的边组成。

### 6. 图同构

两个图同构，要求存在顶点双射，保持邻接关系。

同构图必有：

- 相同顶点数；
- 相同边数；
- 相同度序列；
- 相同连通性；
- 相同回路结构。

但这些条件通常只是必要条件，不是充分条件。

### 7. 补图

简单图 G 的补图 `\bar G`：

- 顶点集相同；
- 两点在补图中相邻，当且仅当它们在 G 中不相邻。

### 8. 常见特殊图

| 图 | 记号 | 特征 |
|---|---|---|
| 完全图 | `K_n` | 任意两点相邻 |
| 圈图 | `C_n` | n 个顶点构成一个圈 |
| 路径图 | `P_n` | n 个顶点构成一条链 |
| 轮图 | `W_n` | 一个中心点连接到圈 |
| 完全二部图 | `K_{m,n}` | 两侧之间全连，侧内无边 |
| 超立方体 | `Q_n` | 顶点为 n 位二进制串，相差一位相邻 |
| 正则图 | r-regular | 每个顶点度都为 r |

### 9. 通路、路径、回路、圈

- 通路 walk：顶点与边交替序列。
- 迹 trail：边不重复的通路。
- 路径 path：顶点不重复的通路。
- 回路 circuit：起点终点相同的迹。
- 圈 cycle：除起终点外顶点不重复的回路。

## 第 14 讲：图的连通性

### 1. 连通关系

无向图中，若 u 与 v 之间存在通路，则称 u 与 v 连通。

该关系是等价关系。

### 2. 连通图与连通分支

- 连通图：任意两点连通。
- 连通分支：由连通关系得到的等价类对应的极大连通子图。

### 3. 重要命题

若简单图 G 不连通，则其补图 `\bar G` 连通。

### 4. 割点与割边

- 割点：删除该顶点后，连通分支数增加。
- 割边/桥：删除该边后，连通分支数增加。

割边判定：

```text
边 e 是割边 ⇔ e 不在任何简单回路中
```

### 5. 点割集与边割集

- 点割集：删除后使图不连通或变为平凡图的顶点集。
- 边割集：删除后使图不连通的边集。

### 6. 点连通度与边连通度

- 点连通度 `κ(G)`：使图不连通或成为平凡图所需删除的最少顶点数。
- 边连通度 `λ(G)`：使图不连通所需删除的最少边数。
- 最小度 `δ(G)`：图中最小顶点度。

Whitney 不等式：

```text
κ(G) ≤ λ(G) ≤ δ(G)
```

更完整上界：

```text
κ(G) ≤ λ(G) ≤ δ(G) ≤ 2|E|/|V|
```

### 7. k-连通与 k-边连通

- G 是 k-连通：`κ(G) ≥ k`。
- G 是 k-边连通：`λ(G) ≥ k`。

## 第 15 讲：欧拉图与哈密顿图

### 1. 欧拉通路与欧拉回路

- 欧拉通路：经过图中每条边恰好一次的通路。
- 欧拉回路：经过图中每条边恰好一次且回到起点的回路。
- 欧拉图：存在欧拉回路的图。
- 半欧拉图：存在欧拉通路但不一定存在欧拉回路的图。

### 2. 欧拉图判定

非平凡连通无向图 G 是欧拉图，当且仅当：

```text
G 中每个顶点度数均为偶数
```

### 3. 半欧拉图判定

连通无向图 G 有欧拉通路但无欧拉回路，当且仅当：

```text
G 中恰有两个奇度顶点
```

欧拉通路必须从一个奇度点开始，在另一个奇度点结束。

### 4. Fleury 算法

构造欧拉回路/通路时：

1. 从合适起点出发；
2. 每一步尽量不走割边；
3. 除非没有其他边可选；
4. 直到所有边都走完。

### 5. 哈密顿图

- 哈密顿通路：经过每个顶点恰好一次的路径。
- 哈密顿回路：经过每个顶点恰好一次并回到起点的回路。
- 哈密顿图：含哈密顿回路的图。
- 半哈密顿图：含哈密顿通路的图。

### 6. 哈密顿图必要条件

若 G 是哈密顿图，则对任意非空真子集 S：

```text
c(G - S) ≤ |S|
```

其中 `c(G-S)` 是删除 S 后的连通分支数。

这个条件只能用于证明“不是哈密顿图”。

### 7. 哈密顿图充分条件

Ore 定理：

若 G 是 n 阶简单图，`n ≥ 3`，且任意不相邻顶点 u, v 都满足：

```text
d(u) + d(v) ≥ n
```

则 G 是哈密顿图。

Dirac 定理是 Ore 定理的推论：

若：

```text
δ(G) ≥ n/2
```

则 G 是哈密顿图。

半哈密顿充分条件：

若任意不相邻顶点 u, v 满足：

```text
d(u) + d(v) ≥ n - 1
```

则 G 有哈密顿通路。

### 8. 欧拉与哈密顿的区别

| 类型 | 关注对象 | 要求 |
|---|---|---|
| 欧拉 | 边 | 每条边恰好一次 |
| 哈密顿 | 顶点 | 每个顶点恰好一次 |

欧拉图有简单判定条件；哈密顿图一般没有简单充要判定。

## 第 16 讲：带权图与最短路

### 1. 带权图

带权图给每条边赋权值：

```text
G = (V, E, w)
```

其中：

```text
w: E → R
```

### 2. 通路的权

通路权值为通路上所有边权之和。

### 3. 单源最短路 SSSP

给定起点 s，求 s 到所有其他顶点的最短路径长度。

### 4. Dijkstra 算法

适用条件：边权非负，课件中以正权连通简单图为主要场景。

核心思想：

1. 初始化起点距离为 0，其余为 ∞。
2. 每次选取未确定顶点中距离最小者 u。
3. 将 u 加入已确定集合 S。
4. 用 u 松弛其邻居：

```text
L(v) = min(L(v), L(u) + w(u,v))
```

5. 重复直到所有顶点确定。

### 5. Dijkstra 注意点

- 每一步要记录：
  - 当前已确定集合 S；
  - 每个顶点的暂定距离；
  - 前驱顶点。
- 若出现负权边，Dijkstra 不一定正确。
- 计算题通常要求写出最短路径和总权值。

### 6. Floyd 算法

用于所有点对最短路。

动态规划思想：

```text
d[i][j] = min(d[i][j], d[i][k] + d[k][j])
```

含义：允许前 k 个顶点作为中间点时，i 到 j 的最短距离。

复杂度：

```text
O(n^3)
```

## 第 17 讲：二部图及其匹配

### 1. 二部图

图 G 是二部图，若顶点集可分为两个不交非空部分：

```text
V = V1 ∪ V2, V1 ∩ V2 = ∅
```

并且每条边都连接 V1 与 V2 中的点，侧内无边。

### 2. 二部图判定

简单图 G 是二部图，当且仅当：

```text
G 中不含奇圈
```

等价算法：尝试用两种颜色给顶点染色，相邻顶点颜色不同。

### 3. 完全二部图

`K_{m,n}`：

```text
|V| = m+n
|E| = mn
```

### 4. 匹配

匹配 M 是边集的子集，满足任意两条边不相邻。

相关概念：

- 极大匹配：不能再加边的匹配。
- 最大匹配：边数最多的匹配。
- 匹配数：最大匹配的边数。
- 完美匹配：每个顶点都被匹配边覆盖。
- 完备匹配：二部图中一侧所有顶点都被匹配。

注意：
- 最大匹配一定极大；
- 极大匹配不一定最大。

### 5. 交错路与增广路

设 M 为匹配。

- M-交错路：边在 M 与不在 M 中交替出现。
- M-可增广路：起点和终点都是 M-非饱和点的交错路。
- 沿可增广路增广：匹配边与非匹配边互换，匹配数增加 1。

### 6. Berge 定理

匹配 M 是最大匹配，当且仅当：

```text
不存在 M-可增广路
```

### 7. Hall 婚姻定理

设二部图 `G=(A,B,E)`，且 `|A|≤|B|`。

存在覆盖 A 的完备匹配，当且仅当对任意 `S⊆A`：

```text
|N(S)| ≥ |S|
```

其中 `N(S)` 是 S 的邻居集合。

### 8. 匹配应用

- 工作分配问题；
- 导师选择问题；
- 棋盘覆盖问题；
- 稳定匹配问题；
- 代表集问题。

棋盘覆盖常用思路：

1. 将棋盘黑白染色。
2. 每个骨牌覆盖一个黑格和一个白格。
3. 若删去后黑白数量不等，则不可能完美覆盖。

## 第 18 讲：树

### 1. 树的定义

树是不含回路的连通简单图。

### 2. 树中路径唯一性

若 T 是树，则任意两个顶点之间存在唯一简单路径。

反过来，若任意两点之间有唯一简单路径，则图是树。

### 3. 树的等价刻画

对简单图 T，以下等价：

1. T 是树。
2. T 连通且无回路。
3. T 中任意两点之间有唯一简单路径。
4. T 连通，删除任意一条边后不连通。
5. T 无回路，任意两个不相邻顶点之间加一条边后产生唯一回路。
6. T 连通且 `m=n-1`。
7. T 无回路且 `m=n-1`。

### 4. 树的边数公式

若树 T 有 n 个顶点、m 条边：

```text
m = n - 1
```

### 5. 连通图边数下界

若 G 是 n 阶连通图，则：

```text
m ≥ n - 1
```

等号成立当且仅当 G 是树。

### 6. 树的叶子

- 度为 1 的顶点称为叶。
- n≥2 的树至少有两个叶。
- 恰有两个 1 度顶点的树是一条链/路径。

### 7. 生成树

图 G 的生成子图若是树，则称为 G 的生成树。

无向图 G 有生成树，当且仅当：

```text
G 连通
```

### 8. 最小生成树 MST

带权连通无向图中，权值总和最小的生成树称为最小生成树。

### 9. Kruskal 算法

1. 将边按权值从小到大排序。
2. 从空边集开始依次选边。
3. 若加入该边不形成回路，则加入。
4. 直到选出 `n-1` 条边。

关键词：**避圈法**。

### 10. Prim 算法

1. 从任意起点开始。
2. 每次选择连接当前树与外部顶点的最小权边。
3. 加入新顶点。
4. 直到包含所有顶点。

关键词：**扩展树**。

### 11. 破圈算法

反复寻找回路，删除该回路中权值最大的边，直到无回路。

### 12. MST 常用性质

- 若一条边是某回路中严格最大权边，则它不在任何 MST 中。
- 若所有边权互不相同，则 MST 唯一。
- Kruskal、Prim 都基于贪心思想。

## 第 19 讲：根树与二叉树

### 1. 有向树与根树

- 有向树：底图是树的有向图。
- 根树：恰有一个入度为 0 的顶点，其余顶点入度为 1。
- 入度为 0 的顶点称为根。

根树中，从根到任意其他顶点有唯一有向路径。

### 2. 根树术语

| 术语 | 含义 |
|---|---|
| 根 | 入度为 0 的顶点 |
| 父亲 | 指向某顶点的前一层顶点 |
| 孩子 | 某顶点指向的下一层顶点 |
| 兄弟 | 同父顶点 |
| 祖先 | 到该点路径上的前驱 |
| 后代 | 从该点出发可达的顶点 |
| 叶 | 没有孩子的顶点 |
| 内点/分支点 | 非叶顶点 |
| 层数 | 根为第 0 层 |
| 高度 | 最大层数 |

### 3. r 叉树

- r 叉树：每个分支点最多有 r 个孩子。
- 正则 r 叉树：每个分支点恰有 r 个孩子。
- 完全 r 叉树：所有叶在同一层。

完全正则 r 叉树，高度为 k 时顶点数：

```text
1 + r + r^2 + ... + r^k = (r^{k+1}-1)/(r-1)
```

### 4. 二叉树

二叉树是 r=2 的根树。  
有序二叉树中区分左子树和右子树。

### 5. 二叉搜索树 BST

满足：

- 每个顶点有唯一关键字；
- 左子树关键字小于根；
- 右子树关键字大于根；
- 左右子树也分别是 BST。

查找、插入、删除平均复杂度与树高有关。

### 6. 平衡二叉树 AVL

任意顶点左右子树高度差不超过 1。

高度满足：

```text
h = O(log n)
```

因此查找效率较高。

### 7. 最优二叉树

叶子带权 `w_i`，叶 v_i 的层数为 `l(v_i)`。

二叉树权：

```text
W(T) = Σ w_i l(v_i)
```

目标：使 W(T) 最小。

### 8. 前缀码

- 任一字符编码都不是另一个字符编码的前缀。
- 可用二叉树表示：
  - 左边标 0；
  - 右边标 1；
  - 每个叶对应一个字符；
  - 根到叶的路径给出编码。

### 9. Huffman 算法

用于构造最优前缀码。

步骤：

1. 每个权值作为一棵单节点树。
2. 取权值最小的两棵树合并。
3. 新树权值为两者之和。
4. 重复直到只剩一棵树。

注意：
- 若最小权值选择不唯一，Huffman 树可能不唯一。
- 但总权值最优。

### 10. 树遍历

| 遍历 | 顺序 |
|---|---|
| 前序 | 根、左、右 |
| 中序 | 左、根、右 |
| 后序 | 左、右、根 |

表达式树相关：
- 中序对应中缀表达式；
- 后序对应逆波兰表达式。

# 第六部分：Problem Set 13–18 高频题型提示

## Problem Set 13：图论导引

重点题型：

1. 求度序列：`K_n, C_n, W_n, K_{m,n}, Q_n`。
2. 用握手定理证明：

```text
δ(G) ≤ 2|E|/|V| ≤ Δ(G)
```

3. 邻接矩阵与图之间互相转换。
4. 判断简单图同构：先比较顶点数、边数、度序列，再看局部结构。
5. 补图与自补图：
   - 若 G 自补，则 `|E(G)| = C(n,2)/2`；
   - 因此 `n(n-1)` 必须能被 4 整除；
   - 所以 `n ≡ 0 或 1 (mod 4)`。

## Problem Set 14：图的连通性

重点题型：

1. 点连通度、边连通度、最小度之间关系。
2. 证明边数足够多则图连通：
   - n 阶简单图若边数大于 `C(n-1,2)`，则连通。
3. 连通图中：
   - `|E| ≥ |V|-1`；
   - 若 `|E| ≥ |V|`，则存在回路。
4. 最长路径端点与割点的关系。
5. 通过构造反例判断命题真假。

## Problem Set 15：欧拉图与哈密顿图

重点题型：

1. 判断欧拉回路/欧拉通路。
2. 完全二部图 `K_{m,n}` 的欧拉性质：
   - 欧拉回路：连通且所有顶点度偶，即 m、n 都为偶数。
   - 欧拉通路：恰有 0 或 2 个奇度顶点。
3. 补图中的欧拉性质。
4. 哈密顿图判定：
   - 二部图有哈密顿回路时，两侧顶点数必须相等；
   - 奇数阶二部图不可能有哈密顿回路。
5. 使用 Dirac/Ore 条件证明存在哈密顿回路。

## Problem Set 16：带权图与最短路

重点题型：

1. 手算 Dijkstra：
   - 每轮选最小暂定距离；
   - 更新邻居；
   - 记录前驱。
2. 手算 Floyd：
   - 按中间点逐步更新距离矩阵。
3. 区分：
   - 单源最短路；
   - 所有点对最短路。
4. 注意课件提示：算法证明类问题主要启发思考，考试重点更可能是算法理解和手算。

## Problem Set 17：二部图及其匹配

重点题型：

1. 证明二部简单图边数上界：

```text
|E| ≤ |V|^2 / 4
```

2. 计数完美匹配。
3. 找交错路、可增广路，并通过增广得到最大匹配。
4. 用 Hall 定理证明完备匹配存在。
5. 棋盘覆盖问题：
   - 黑白染色；
   - 骨牌覆盖一黑一白；
   - 黑白数量不同则不可能覆盖。

## Problem Set 18：树

重点题型：

1. 画非同构树。
2. 用树的度数公式：

```text
Σ d(v) = 2(n-1)
```

3. 判断一个正整数序列是否可作为树的度数序列：
   - 所有度数正；
   - 总和为 `2(n-1)`。
4. Kruskal 算法求 MST。
5. MST 唯一性：
   - 所有边权不同 ⇒ MST 唯一。
6. 回路性质：
   - 回路中严格最大权边不在任何 MST 中。


## 易错点

- `p → q` 只有 p 真 q 假时为假。
- “只有 A 才 B”翻译为 `B → A`。
- 极大元不一定最大元。
- 极大匹配不一定最大匹配。
- 二部图的核心判定是“无奇圈”。
