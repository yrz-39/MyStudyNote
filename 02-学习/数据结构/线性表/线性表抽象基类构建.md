# 线性表 linear list
## 1.整体概念
线性表就是数据按照线性结构存储排列
```text
L = {a, b, c, d}
```
每个元素有一个前驱和一个后缀,头尾元素除外
- 链表,数组,队列,栈都属于线性表

## 2.基本操作
线性表有一些基本操作,通过C++的抽象类的纯虚函数来提供接口
```cpp
template<typename T>
class LinearList{
private:
	//具体实现,取决于要求和使用情况
public:
	LinearList();
	~LinearList();
	virtual int size() const = 0;
	virtual int length() const = 0;//这里一般length是长度，size是最大容量
	virtual bool empty() const = 0;
	virtual int search(T& x) const = 0;
	virtual bool getData(int i,T& x) = 0;
	virtual void setData(int i,T& x) = 0;
	virtual bool insert(int i,T& x) = 0;
	virtual bool remove(int i,T& x) = 0;
};
```
- 有了抽象类之后,一些具体的线性表就可以通过继承这个抽象类进行定义
