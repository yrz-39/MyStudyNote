# 线性表 Linear List

线性表是所有线性结构数据结构的统称。各种具体实现均继承自抽象基类 [[线性表/线性表抽象基类构建|LinearList]]。

---

## 实现分类

| 数据结构 | 存储方式 | 关键特性 | 笔记 |
|---------|---------|---------|------|
| **顺序表** | 数组（连续存储） | 随机访问 O(1)，插入/删除 O(n) | [[线性表/顺序表]] |
| **链表** | 节点 + 指针（链式存储） | 顺序访问 O(n)，插入/删除 O(1) | [[线性表/链表]] |
| **栈** | 依赖底层实现 | 后进先出 LIFO | [[线性表/栈]] |
| **队列** | 依赖底层实现 | 先进先出 FIFO | [[线性表/队列]] |

---

## 时间复杂度对比

| 操作 | 顺序表 | 链表 | 栈 | 队列 |
|------|-------|------|----|----|
| 随机访问 | O(1) | O(n) | 仅栈顶 O(1) | 仅队头/队尾 O(1) |
| 插入 | O(n) | O(1) | O(1) | O(1) |
| 删除 | O(n) | O(1) | O(1) | O(1) |
| 搜索 | O(n) | O(n) | O(n) | O(n) |

---

## 关系图

```
LinearList（抽象基类）
├── SeqList（顺序表）    — 数组实现
├── LinkList（链表）     — 指针实现
├── Stack（栈）          — LIFO
└── Queue（队列）         — FIFO
```
