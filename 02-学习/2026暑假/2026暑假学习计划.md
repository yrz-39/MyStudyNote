# 2026 暑假学习计划

> [!summary] 这个暑假的目标
> 不提前把大二课程“学完”，而是完成三件事：
> 1. 让[[数据结构]]与 [[ICS]] 开学时不再陌生；
> 2. 建立 C++、Linux / WSL 与 Python 的分工和手感；
> 3. 做出一个小而完整的 AI 应用，保留创造欲。

## 已知课程与基础

### 下学期课程

- ICS（计算机系统基础）
- 数据结构
- 离散数学 II
- 网络攻防
- 概率论

### 现有基础

- 已学习《程序设计基础》《计算机程序的构造和解释》；
- 有微积分、线性代数基础；
- 已系统学习基于 RISC-V 的计算机组成，对 CPU 有基本理解；
- 数据结构课主要使用 C++；
- Windows 有 MSYS2 UCRT64 C++ 工具链与 Qt Creator；
- Ubuntu WSL 已配置 GCC、GDB、Make、Binutils，适合做 ICS / Linux 实验。

## 总策略

| 主线 | 权重 | 目标 |
|---|---:|---|
| 数据结构（C++） | 30% | 实现、复杂度分析、调试 |
| ICS（系统与 Linux 实验） | 30% | 建立程序—机器—系统的连贯理解 |
| 网络基础 / 网络攻防预热 | 10% | 协议与网络直觉，优先观察与授权实验 |
| 概率论 | 10% | 建立随机变量、期望与方差的直觉 |
| 离散数学 II | 5% | 复习前置基础，具体内容跟随课程 PPT |
| AI 应用项目 | 15% | 用 Python 做出一个可运行的小作品 |

```text
C++：理解、实现、调试数据结构
Ubuntu WSL：做 ICS、Linux、编译链接与系统实验
Python：做 AI 网站或小工具，把想法变成作品
```

## 节奏规则

- 全程按 **三天一个弹性周期** 组织，不制定每日强制安排；
- 每个周期只要求完成一个“核心目标”；状态好时再完成“有余力再做”；
- 若旅行、办事或状态不佳：核心目标可以顺延，扩展目标直接放弃，**不补债**；
- 不把每个数据结构机械翻译成 Python；遵循：**C++ 用来理解和实现，Python 用来组合和交付。**
- 离散数学 II 不提前硬啃群、环等内容，开学后以教师 PPT、作业和符号体系为准。

# 三条主线的最低成果

## 数据结构仓库

到开学前，尽量留下：

```text
动态数组
链表
栈
队列
二叉搜索树
堆或哈希表
一种排序算法
```

每个实现至少包含：

- 基本操作；
- 若干边界测试；
- 时间 / 空间复杂度说明；
- 一两句踩坑记录。

## ICS 实验笔记

建立下面这条主线即可，不必看完全部课程：

```text
数据表示
→ C 与汇编
→ 目标文件
→ 链接
→ 程序执行
→ Cache
→ 虚拟内存
→ 系统调用 / I/O
```

建议留下的实验：

```text
补码与溢出
指针 / 内存布局
函数调用与栈帧
C 到汇编
目标文件与符号
静态 / 动态链接
Cache / 局部性观察
```

## AI 应用项目

默认项目：**AI 学习助手网站**。

最小可用版本：

```text
输入一段课程笔记
→ 保存到本地
→ 点击按钮
→ AI 生成复习提纲或问答卡
```

建议技术栈：

```text
Python
+ FastAPI
+ HTML / CSS / JavaScript
+ SQLite
+ OpenAI-compatible API
```

第一版不加入：RAG、向量数据库、多 Agent、复杂长期记忆、Live2D 或桌宠动画。先完成一个稳定可运行的 MVP。

# 环境分工

```text
Windows + Qt Creator / MSYS2
    └── 数据结构 C++、普通作业、桌宠与 GUI 工具

Ubuntu WSL + VS Code
    └── ICS、GCC / GDB、ELF、Linux 命令、FastAPI 后端

Python
    └── AI 网站、小工具、概率模拟
```

> [!important] 最低原则
> 每个三天周期，只求完成一个核心目标；每一次兴趣起来时，再多走一点。暑假结束时，重要的不是计划是否打满，而是能否更自然地写 C++、理解程序怎样运行，并做出一个属于自己的小作品。
