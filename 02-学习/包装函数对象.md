# C++如何表示/传递/持有可调用对象？
## 1. 为什么需要包装函数对象
- [[程序设计中回调函数的设计]]中回调的本质就是“把未来要执行的行为”作为参数传递,所谓行为最主要的就是各种函数
- C++中可调用对象不只有函数指针(C风格)
	- 普通函数
	- 成员函数+对象
	- lambda
	- functor(重载operator()的对象)
	- std::bind生成的对象
- 因此需要统一的"包装方式"来接收这些不同来源的可调用对象

## 2. 设计层次
### 2.1 最普通形式：函数指针
```cpp
void (*f)(int)

using FuncPointer = void (*)(int);
FuncPointer f;
```
特点：
- 轻量
- 只能表示普通函数/无捕获lambda()
