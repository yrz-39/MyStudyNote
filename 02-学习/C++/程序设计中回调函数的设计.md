# 回调函数
## 1.概念
- 回调函数：把一段代码作为参数传给另一个函数，让对方再合适的时机再调用它

## 2.为什么需要回调函数
 - 普通函数调用：A 调用 B
 - 回调函数：A 把函数 f 交给 B, B 在未来某个时间调用F
### 2.1 回调函数解决的问题
1. 让代码更灵活
2. 把“固定流程”和“可变行为”分开
3. 支持事件处理
4. 支持异步任务完成后的通知
5. 支持算法中的自定义规则
```cpp
sort(v.begin(),v.end(),cmp) //这里的cmp就可以理解为一个回调
```
## 3.回调函数实现方式(c++)
### 3.1 普通函数指针
```cpp
#include <iostream>
using namespace std;

void printMessage() {
    cout << "This is a callback." << endl;
}

void execute(void (*func)()) {
    func();
}

int main() {
    execute(printMessage);
}
```
- 这里的 `void (*func)()` 是一个指向函数的指针，这个函数没有参数，返回值是`void` 函数名本身就可以作为一个指针，指向函数块所在的地址
- 也可以带参数`void (*func)(int)` 
#### 3.11 使用using 简化函数指针
```cpp
using Callback = void (*)(int);

void execute(Callback func,int value){
	func(value);
}
```
- `Callback` 是一种函数指针类型，指向“参数为int,返回值为void”的函数

### 3.2 Lambda 表达式作为回调
- lambda表达式见 [[C++中的lambda表达式与python的lambda表达式的比较]] 
```cpp
#include <iostream>
using namespace std;

void execute(void (*func)()) {
    func();
}

int main() {
    execute([]() {
        cout << "Lambda callback" << endl;
    });
}
```
- 这里的lambda表达式是 `[]()->void { cout<< "Lambda callback" }`

### 3.3 std::function 作为回调
- `std::function` 是[[包装函数对象]] 

```cpp
#include <iostream>
#include <functional>
using namespace std;

void execute(function<void()> func) {
    func();
}

int main() {
    int x = 10;

    execute([x]() {
        cout << "x = " << x << endl;
    });
}
```
- 对于`function<void()> func` func是一个可调用对象，其形式是：没有参数，返回值是void,也可以带参数 `function<void(int)> func`

### 3.4 成员函数回调
- 普通成员函数不能直接当成普通函数指针使用，因为它依赖某个对象
- 所以回调成员函数通常需要知道“哪个对象”和“调用哪个成员函数”
```cpp
#include <iostream>
#include <functional>
using namespace std;

class Printer {
public:
    void print() {
        cout << "Printer::print" << endl;
    }
};

void execute(function<void()> func) {
    func();
}

int main() {
    Printer p;

    execute([&p]() { //这里要有外部的捕获，告诉函数对象是p引用捕获可以同时修改原p
        p.print();
    });
}
```

## 4. 回调函数的典型应用场景
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {3, 1, 4, 2};

    sort(v.begin(), v.end(), [](int a, int b) {
        return a > b;
    });

    for (int x : v) {
        cout << x << " ";
    }
}
```
- 这里的`[](int a,int b){ return a > b; }`
